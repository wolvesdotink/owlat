# Each line is `<route|deferred> <KiB> <key>`: the most gzip (level 9, KiB of
# 1024 bytes) that the static JavaScript closure of a page or lazily loaded
# chunk may add on top of the entry closure. The key is the report's key for
# that row. The entry closure itself is budgeted by GZIP_BUDGET_KB in
# scripts/check-bundle-budget.ts.
#
# Rule: the largest size in the `web-bundle-<sha>` CI reports of the green
# main commits 7684bc6bd..69c55d4ce (21 builds, same image toolchain), plus the
# larger of 10% and 2 KiB, rounded up to a whole KiB (suggestedBudgetKiB in
# scripts/bundle-closure.ts). The 2 KiB floor keeps small chunks from failing
# on a few lines of copy.
#
# A new page or lazy chunk fails until it has a line; the failure prints one
# with the same rule applied to that build. A line whose closure is gone fails
# until it is deleted. A closure over its budget first moves the new code off
# the page's static imports (a dynamic import(), defineAsyncComponent, a
# smaller leaf module). Raise a line only with the reason in the pull request:

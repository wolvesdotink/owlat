---
title: 'AI clients (MCP)'
description: 'Let an AI app such as Claude Desktop, Claude Code or Cursor search and read your Postbox mail over MCP, read-only, with a token you create and can revoke.'
---

If you already work in an AI app, it can look things up in your mail for you:
"find the contract Mia sent and summarise the payment terms". Owlat serves an
MCP server for this. You create a token for each app, pick the mailboxes it may
read, and paste the token into the app.

::callout{type="info" title="Off by default"}
An admin turns it on under **Settings → Features → AI clients (MCP)** (flag
`mail.mcp`). It needs Postbox or a connected mailbox. Turning it off cuts off
every connected app at once.
::

## Connect an app

1. Open **My settings → AI clients** and choose **Connect a client**.
2. Give it a name you will recognise later, and tick the mailboxes it may read.
   Only mailboxes you see in your own Postbox are offered, including team
   inboxes you belong to.
3. Copy the token. Owlat shows it once and keeps only a hash of it.
4. Add the server to your app. The dialog shows a ready configuration for
   Claude Desktop, Cursor and other clients, and a command for Claude Code:

```sh
claude mcp add --transport http owlat https://<your-convex-site-url>/mcp/postbox \
  --header "Authorization: Bearer <token>"
```

The server address is your Owlat backend's site URL followed by
`/mcp/postbox`. It uses the Streamable HTTP transport.

## What an app can do

Every connection is read-only. It can:

- list the mailboxes it was given, and their folders and labels,
- search mail with the same syntax as the Owlat search box (`from:`,
  `subject:`, `label:`, `in:inbox`, `is:unread`, `after:`, `OR`, ...),
- read a conversation, with plain-text bodies and attachment names.

It cannot send, move, label, archive or delete mail, and reading a conversation
does not mark it read. Very large message bodies come back as their snippet.

::callout{type="warning" title="Mail leaves Owlat"}
Whatever the app reads goes to the app and to the AI provider behind it. Only
give a connection the mailboxes you are willing to share with that provider.
::

## Mail is data, not instructions

Mail is written by other people, and some of it tries to give orders to an AI.
Owlat returns every message as data marked untrusted, says so in each tool
description, and withholds text that looks like an attempt to instruct the
model, the same filter the Owlat assistant uses. Your app still decides what
to do with what it reads, so keep its own confirmation prompts on.

## Access and revoking

A connection never reaches more than you do. Every call checks again that you
are still a member of the workspace, that you can still open each mailbox, and
that the feature is on. Leave a team inbox and its mail disappears from the
connection on the next call.

**Activity** next to each connection lists what it did: which tool, the search
text, how many results. **Revoke** cuts the app off at once; its activity
stays listed.

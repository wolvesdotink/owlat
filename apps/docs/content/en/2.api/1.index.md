Owlat exposes authenticated API endpoints under your Convex site URL.

## Base URL

Use your deployment URL:

```txt
https://<your-deployment>.convex.site
```

Authenticated endpoints are currently under:

```txt
/api/v1/*
```

## Authentication

Send your API key in `Authorization`:

```txt
Authorization: Bearer lm_live_...
```

API keys are created in **Settings → API**.

## SDKs

For server-side integrations, use an official SDK instead of raw HTTP calls:

- [TypeScript SDK](/api/sdk) -- `@owlat/sdk-js` for Node.js, Bun, and Deno
- [Java SDK](/api/sdk-java) -- `com.owlat:owlat-sdk` for JVM applications (Java 11+)

## OpenAPI document

The request and response shapes of every `/api/v1` operation are declared once,
in the `@owlat/public-contract` package. The API server validates requests with
it, the TypeScript SDK takes its types from it, and the Java SDK's tests check
the SDK against the OpenAPI 3.1 document generated from it:
[`packages/public-contract/openapi.json`](https://github.com/wolvesdotink/owlat/blob/main/packages/public-contract/openapi.json).
Point an API client generator or an HTTP tool at that file to get every path,
schema and example.

After changing the contract, regenerate the document and commit it with the
change:

```bash
bun run --cwd packages/public-contract openapi
```

CI fails when the committed document is out of date
(`bun run --cwd packages/public-contract openapi:check`).

## Response format

Most endpoints return JSON in this shape:

```json
{
  "data": {}
}
```

Errors use the locked Operation-error envelope — a human-readable `message`, a
closed `category`, and an optional `data` object carrying specifics:

```json
{
	"error": {
		"category": "invalid_input",
		"message": "Human readable message",
		"data": { "field": "email" }
	}
}
```

`category` is one of: `unauthenticated` (401), `limit_reached` (402),
`forbidden` (403), `not_found` (404), `invalid_input` (400), `already_exists`
(409), `conflict` (409), `invalid_state` (422), `rate_limited` (429),
`internal` (500).

One exception: a request to an existing path with an unsupported method answers
`405` and carries `invalid_input`. The status is the transport's, not the
category's — every other response's status is the one listed above.

## CORS

Private API endpoints (`/api/v1/*`) are restricted by the `ALLOWED_ORIGINS` environment variable. Set it to a comma-separated list of allowed origins in the Convex dashboard:

```bash
npx convex env set ALLOWED_ORIGINS "https://app.example.com,http://localhost:3000"
```

Public endpoints (forms, unsubscribe, preference center) allow all origins.

## Rate limits

Authenticated API requests are limited to **10 requests per second** per API key.

Headers:

```txt
X-RateLimit-Limit
X-RateLimit-Remaining
X-RateLimit-Reset
```

When exceeded, responses return `429` with `Retry-After`.

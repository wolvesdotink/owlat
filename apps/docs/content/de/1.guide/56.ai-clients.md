description: 'Lass eine KI-App wie Claude Desktop, Claude Code oder Cursor deine Postbox-Mail über MCP durchsuchen und lesen, nur lesend, mit einem Token, das du erstellst und widerrufen kannst.'
---

Wenn du ohnehin in einer KI-App arbeitest, kann sie für dich in deiner Mail
nachsehen: „Finde den Vertrag, den Mia geschickt hat, und fasse die
Zahlungsbedingungen zusammen.“ Owlat stellt dafür einen MCP-Server bereit. Du
erstellst für jede App ein Token, wählst die Postfächer, die sie lesen darf,
und trägst das Token in der App ein.

::callout{type="info" title="Standardmäßig aus"}
Eine Administratorin oder ein Administrator schaltet es unter **Einstellungen →
Features → KI-Programme (MCP)** ein (Flag `mail.mcp`). Es braucht die Postbox
oder ein verbundenes Postfach. Wird es ausgeschaltet, verlieren alle
verbundenen Apps sofort den Zugriff.
::

## Eine App verbinden

1. Öffne **Meine Einstellungen → KI-Programme** und wähle **Programm verbinden**.
2. Gib ihr einen Namen, an dem du sie später erkennst, und hake die Postfächer
   an, die sie lesen darf. Angeboten werden nur Postfächer, die du in deiner
   eigenen Postbox siehst, auch Team-Postfächer, in denen du Mitglied bist.
3. Kopiere das Token. Owlat zeigt es einmal an und speichert nur einen Hash.
4. Trage den Server in deiner App ein. Der Dialog zeigt eine fertige
   Konfiguration für Claude Desktop, Cursor und andere Programme und einen
   Befehl für Claude Code:

```sh
claude mcp add --transport http owlat https://<your-convex-site-url>/mcp/postbox \
  --header "Authorization: Bearer <token>"
```

Die Serveradresse ist die Site-URL deines Owlat-Backends, gefolgt von
`/mcp/postbox`. Sie nutzt den Streamable-HTTP-Transport.

## Was eine App kann

Jede Verbindung ist nur lesend. Sie kann:

- die Postfächer auflisten, die sie bekommen hat, mit ihren Ordnern und Labels,
- Mail mit derselben Syntax wie im Owlat-Suchfeld durchsuchen (`from:`,
  `subject:`, `label:`, `in:inbox`, `is:unread`, `after:`, `OR`, ...),
- eine Unterhaltung lesen, mit Textinhalt und den Namen der Anhänge.

Sie kann keine Mail senden, verschieben, labeln, archivieren oder löschen, und
das Lesen einer Unterhaltung markiert sie nicht als gelesen. Sehr große
Nachrichten kommen nur als Vorschau zurück.

::callout{type="warning" title="Mail verlässt Owlat"}
Was die App liest, geht an die App und an den KI-Anbieter dahinter. Gib einer
Verbindung nur die Postfächer, die du mit diesem Anbieter teilen willst.
::

## Mail ist Inhalt, keine Anweisung

Mail schreiben andere Leute, und manche Mail versucht, einer KI Befehle zu
geben. Owlat liefert jede Nachricht als Daten aus, als nicht vertrauenswürdig
markiert, sagt das in jeder Werkzeugbeschreibung und hält Text zurück, der wie
ein Versuch aussieht, dem Modell Anweisungen zu geben, mit demselben Filter wie
der Owlat-Assistent. Was die App mit dem Gelesenen tut, entscheidet sie selbst,
also lass ihre eigenen Rückfragen eingeschaltet.

## Zugriff und Widerruf

Eine Verbindung reicht nie weiter als du. Bei jedem Aufruf prüft Owlat erneut,
dass du noch Mitglied des Workspace bist, dass du jedes Postfach noch öffnen
kannst und dass die Funktion eingeschaltet ist. Verlässt du ein Team-Postfach,
verschwindet seine Mail beim nächsten Aufruf aus der Verbindung.

**Aktivität** neben jeder Verbindung zeigt, was sie getan hat: welches
Werkzeug, der Suchtext, wie viele Treffer. **Widerrufen** sperrt die App sofort
aus; ihre Aktivität bleibt sichtbar.

Der KI-Assistent ist ein dialogfähiger Helfer, der die eigenen Daten Ihres Workspace durchsuchen kann — Wissen, Dateien, Kontakte, Vorlagen und Kampagnen — und auf Wunsch E-Mail- und Kampagnentexte entwirft. Anders als ein einmaliges Suchfeld führt er ein mehrstufiges Gespräch, streamt seine Antwort während des Schreibens und zeigt Ihnen, welche Tools er verwendet hat. Er ist unter **Dashboard → Assistent** (`/dashboard/assistant`) zu finden und lässt sich außerdem im [Team-Chat](/guide/chat) mit `@assistant` hinzuziehen.

::callout{type="info" title="Hinter einem Feature-Flag"}
Der Assistent ist durch das Feature-Flag `ai.assistant` abgesichert (das wiederum das Master-Flag `ai` und einen konfigurierten LLM-Anbieter voraussetzt) und ist standardmäßig deaktiviert. Ein Owner oder Admin aktiviert ihn unter [Feature-Flags](/guide/feature-flags). Die Erwähnung `@assistant` im Team-Chat benötigt zusätzlich das Flag `chat`.
::

## Der persönliche Assistent

`/dashboard/assistant` ist eine private Oberfläche im Stil von ChatGPT. Jede Konversation gehört **Ihnen** — kein anderes Teammitglied kann Ihre Konversationen sehen, und Sie können mehrere gleichzeitig führen (eine pro Thema). Starten Sie eine neue mit **Neuer Chat**, löschen Sie Konversationen aus der Liste und nehmen Sie einen alten Verlauf jederzeit wieder auf.

Während der Assistent antwortet, streamt seine Antwort Token für Token herein. Muss er etwas nachschlagen, ruft er zuerst ein **Tool** auf; Sie sehen dann eine aufklappbare Karte, die zeigt, welches Tool gelaufen ist (z. B. *Wissen durchsucht*), bevor die Antwort weitergeht. Mit **Stopp** beenden Sie eine Antwort vorzeitig — was bereits gestreamt wurde, bleibt erhalten.

## Was der Assistent kann

Der Assistent verfügt über einen festen Satz von **Lese- und Entwurfs-Tools**. Er kann alles finden und darüber schlussfolgern, was Sie selbst sehen könnten, und er kann Entwürfe für Sie schreiben — aber er kann niemals Mail versenden, einen Kontakt ändern oder von sich aus irgendeinen Zustand im Workspace verändern.

| Tool | Was es tut |
| --- | --- |
| Wissen durchsuchen | Hybride Suche über den [Wissensgraphen](/guide/knowledge-graph) — Fakten, Entscheidungen und Präferenzen, die aus Ihren Konversationen extrahiert wurden. |
| Dateien durchsuchen | Semantische Suche über Ihre hochgeladenen [Dateien](/guide/files). |
| Workspace durchsuchen | Volltextsuche über Kontakte, E-Mail-Vorlagen, transaktionale E-Mails und Kampagnen. |
| Kampagnen- / E-Mail-Statistiken | Zustell-, Öffnungs-, Klick-, Bounce- und Abmeldezahlen für eine Kampagne oder über einen aktuellen Zeitraum. |
| E-Mail-Antwort entwerfen | Schreibt nach Ihren Vorgaben eine professionelle E-Mail an einen Kontakt — als Text zurückgegeben, den Sie prüfen und selbst versenden. |
| Kampagnentext entwerfen | Schreibt Betreff + Textkörper einer Kampagne aus einem Briefing — als Text zurückgegeben. |

Fördern die Tools nichts Relevantes zutage, sagt der Assistent das, statt eine Antwort zu erfinden.

## @assistant im Team-Chat

Erwähnen Sie in einem beliebigen Kanal oder einer DM `@assistant`, um die KI ins Gespräch zu holen. Sie liest die jüngsten Nachrichten im Raum als Kontext, kann dieselben Tools aufrufen und postet eine gestreamte Antwort, die **alle im Raum sehen können**. Nutzen Sie das, um einen Verlauf zusammenzufassen, eine Zahl herauszusuchen oder gemeinsam eine Antwort zu entwerfen. Der Assistent antwortet nur, wenn er ausdrücklich erwähnt wird — er schaltet sich niemals von selbst in ein Gespräch zwischen Menschen ein.

## Datenschutz & Sicherheit

- **Persönliche Konversationen sind privat** für ihre Besitzerin oder ihren Besitzer; `@assistant`-Antworten in einem Raum sind für dessen Mitglieder sichtbar, wie jede andere Nachricht auch.
- Der Assistent liest die Daten Ihrer Organisation **organisationsweit** (derselbe Trusted-Member-Geltungsbereich, der über alle KI-Funktionen von Owlat hinweg verwendet wird). Jedes Tool läuft in diesem Geltungsbereich — es kann keine Daten außerhalb Ihres Workspace erreichen.
- **Abgerufene Inhalte werden als Daten behandelt, niemals als Anweisungen.** Text aus E-Mails, Dateien oder Kontaktdatensätzen wird auf Prompt-Injection-Versuche geprüft und zurückgehalten, bevor er das Modell erreicht — ein bösartiges Dokument kann den Assistenten also nicht kapern.
- Die Entwurfs-Tools **liefern ausschließlich Text zurück.** Nichts, was der Assistent tut, versendet eine E-Mail oder schreibt in Ihre Daten — Sie behalten die Kontrolle über jede Aktion.
- Tokenverbrauch und Modell werden pro Konversation erfasst, damit KI-Kosten in Ihrem bestehenden Nutzungsreporting sichtbar bleiben. Eine Obergrenze für Tool-Schritte pro Zug und ein Ratenlimit pro Benutzer halten Endlosschleifen in Schach.

::callout{type="info" title="Bring your own model"}
Der Assistent nutzt den LLM-Anbieter, den Sie für Owlat konfiguriert haben (OpenAI, OpenRouter, ein lokales Ollama-Modell oder einen OpenAI-kompatiblen Claude-Proxy). Tool-Calling setzt ein Modell voraus, das Function Calling unterstützt. Zur Anbieterkonfiguration siehe [Feature-Flags](/guide/feature-flags).
::

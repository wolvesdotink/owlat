Postbox gibt jedem Teammitglied ein persönliches Postfach auf Ihrer Owlat-Domain — mit Webmail-Oberfläche und vollem IMAP/SMTP, sodass jeder native Client genutzt werden kann (Apple Mail, Thunderbird, mobile Mail-Apps).

Es ist getrennt von Marketing-Kampagnen und dem gemeinsamen Team-Postfach. Postbox ist für die alltägliche E-Mail von Mensch zu Mensch da; Kampagnen sind für Massenversand; das Team-Postfach ist für gemeinsame Triage.

::callout{type="info" title="Feature-Flag"}
Postbox ist **standardmäßig deaktiviert**. Aktivieren Sie es unter **Einstellungen → Features** oder mit `owlat-setup feature postbox on`. Das Aktivieren des Flags aktiviert außerdem das Docker-Compose-Profil `personal-mail`, das den IMAP-Server (`apps/imap`) startet.
::

Es gibt zwei Wege, persönliche Mail auf Owlat zu betreiben. Ein **gehostetes Postfach** (Flag `postbox`) ist eine von Owlat gehostete Adresse auf einer von Ihnen verifizierten Domain — Owlat ist dabei der Mailserver. Alternativ können Sie ein **externes Postfach verbinden** (das separate Flag `mail.external`) und Ihr bestehendes Gmail-, Fastmail- oder Firmenkonto weiterverwenden, während Owlat es über IMAP/SMTP synchronisiert. Es sind unabhängige Flags; Sie können das eine, das andere, beide oder keines betreiben.

## Was Sie bekommen

- Postfächer pro Benutzer mit Ordnern (Posteingang, Gesendet, Entwürfe, Papierkorb, Spam, Archiv) sowie eigenen Labels
- Eine Webmail-Oberfläche unter `/dashboard/postbox`
- Nativer IMAP4rev1-Server (Port 993, TLS) und SMTP-Submission für ausgehende Mail
- App-Passwörter, um native Clients zu verbinden, ohne Ihr Kontopasswort preiszugeben
- Adress-Aliasse — Mail an mehreren Adressen in einem Postfach empfangen
- Filterregeln pro Postfach (Sieve-ähnlich): auf Absender/Empfänger/Betreff/Text matchen und dann verschieben, labeln, als gelesen markieren, mit Stern versehen, weiterleiten, in den Papierkorb legen oder verwerfen
- Weiterleitungsregeln
- Signaturen pro Identität
- Abwesenheitsnotiz mit Zeitraum
- Zurückstellen (Snooze): einen Thread bis zu einem von Ihnen gewählten Datum ausblenden
- Eine [Antwort-Warteschlange](/guide/reply-queue) — eine Aufgabenliste der E-Mails, die auf Ihre Antwort warten, mit optionalen KI-Zusammenfassungen der Fragen und einer Dringlichkeitsreihung
- Geplanter Versand und ein Zeitfenster zum Rückgängigmachen
- Ein persönliches Adressbuch, das Empfänger automatisch vervollständigt
- Zwei Verfassen-Modi (einfacher Rich Text oder der vollständige blockbasierte Builder)
- Suche mit Operatoren im Gmail-Stil
- Threading über Antworten und Weiterleitungen hinweg
- Blockieren entfernter Bilder und Zusammenklappen zitierten Texts per Klick beim Lesen
- Datenschutzhilfen beim Lesen: Dark-Mode-Anpassung empfangener HTML-Mail, Blockieren von Tracking-Pixeln, Abmeldung per Klick und Transparenz über Linkziele
- Gruppierung durch die [Smart Inbox](/guide/smart-inbox) (Personen / Newsletter / Benachrichtigungen / Belege) und eine gebündelte [Referenz der Postbox-Einstellungen](/guide/postbox-settings)
- **Externes Postfach verbinden** (separates Flag `mail.external`): Ihr eigenes Gmail-/Fastmail-/Firmenkonto über IMAP+SMTP nutzen, ganz ohne Versanddomain

## Ihr Postfach einrichten

Postfächer werden beim ersten Besuch nicht automatisch angelegt — sie werden ausdrücklich bereitgestellt. Es gibt zwei Wege:

- **Vorabreservierung durch Admins bei der Einladung** — ein Admin kann die Adresse für ein neues Mitglied schon beim Einladen festlegen, sodass das Postfach im Moment der Annahme bereitsteht.
- **Selbstbedienung aus den Postbox-Einstellungen** — öffnen Sie **Postbox → Einstellungen → Konto hinzufügen**, wählen Sie einen lokalen Teil und eine verifizierte Domain aus der Auswahlliste (`marcel` + `@yourdomain`). Die Adresse wird beim Absenden angelegt.

::callout{type="info" title="Ein gehostetes Postfach anzulegen erfordert Adminrechte"}
Das Bereitstellen eines gehosteten Postfachs erfordert Adminrechte (`mailbox.create` läuft im Admin-Kontext). Außerdem brauchen Sie mindestens eine verifizierte Domain — verifizieren Sie zuerst eine unter **Einstellungen → Domains**.
::

Sobald das Postfach existiert:

1. Öffnen Sie **Postbox → Einstellungen → Aliasse** und fügen Sie alle weiteren Adressen hinzu, unter denen Sie Mail empfangen möchten. Diese müssen auf einer Domain liegen, die bereits in Owlat konfiguriert ist und deren MX-Einträge auf Ihren MTA zeigen.
2. (Optional) Öffnen Sie **Einstellungen → Signaturen** und legen Sie für jede Absenderadresse eine Signatur an.

Das war es für den Empfang von Mail. Um aus einem gehosteten Postfach zu senden, benötigen Sie außerdem die unter **Einstellungen → Domains** konfigurierte Versanddomain (dieselbe DKIM-/SPF-Einrichtung wie auf der Marketing-Seite).

## Ein externes Postfach verbinden

Wenn Sie keine gehostete Adresse möchten — oder keine Domain zum Verifizieren haben —, können Sie Ihre eigene mitbringen. Die Fähigkeit **Externes Postfach verbinden** erlaubt es jeder Person, ein bestehendes Gmail-, Fastmail-, iCloud-, Outlook.com- oder Firmenkonto über IMAP + SMTP anzubinden. Owlat hält es synchron und lässt Sie darin lesen, suchen und daraus senden — alles in derselben Postbox-Oberfläche, ohne eine Versanddomain zu registrieren.

Dies ist ein **eigenes Feature-Flag (`mail.external`)**, getrennt vom gehosteten Postbox. Das Aktivieren schaltet das Docker-Compose-Profil `external-mail` frei, das den mail-sync-Worker (`apps/mail-sync`) startet, der IMAP/SMTP mit Ihrem Anbieter spricht.

::steps

### Den Verbindungsablauf öffnen

Gehen Sie zu **Postbox → Einstellungen → Externes Postfach** (oder **Konto hinzufügen → Externes Postfach verbinden**).

### Voreinstellung wählen oder Serverdaten eingeben

Schaltflächen zur Schnelleinrichtung füllen IMAP-/SMTP-Host und -Port für **Gmail**, **Fastmail**, **iCloud** und **Outlook.com** vor. Andernfalls geben Sie IMAP-Host/-Port und SMTP-Host/-Port manuell ein, mit einem SSL-Schalter pro Server.

### Ihre Zugangsdaten eingeben

Geben Sie die E-Mail-Adresse, den Benutzernamen (voreingestellt die E-Mail-Adresse) und das Passwort an. Für Gmail / Outlook benötigen Sie ein **App-Passwort** bei aktivierter Zwei-Faktor-Authentifizierung. Zugangsdaten werden verschlüsselt gespeichert — Lese-Abfragen geben sie niemals zurück.

### Testen, dann verbinden

Klicken Sie auf **Verbindung testen**, um IMAP und SMTP unabhängig voneinander zu prüfen, und danach auf **Postfach verbinden**. Der mail-sync-Worker verbindet sich und beginnt zu synchronisieren; die Verbindung zeigt einen Live-Status (Verbinde, Verbunden, Authentifizierung fehlgeschlagen oder Verbindungsfehler).

::

::callout{type="info" title="Extern vs. gehostet"}
Ein externes Postfach ist auf Ihrem lokalen MTA **nicht** autoritativ — eingehende Mail wird weiterhin von Ihrem Anbieter zugestellt und dann hereinsynchronisiert, nicht über den MX von Owlat. Ausgehende Mail läuft über das SMTP Ihres Anbieters. Sie können Zugangsdaten jederzeit auf derselben Seite aktualisieren oder die Verbindung trennen; das Trennen beendet die Synchronisierung, bereits synchronisierte Nachrichten bleiben erhalten.
::

## Mail verfassen

Klicken Sie in jedem Ordner auf **Verfassen**. Der Composer unterstützt Rich Text, Anhänge, Antworten/Weiterleiten, (automatisch gespeicherte) Entwürfe und den Wechsel zwischen Identitäten, wenn Ihr Postfach mehrere Absenderadressen hat. Die Empfängerfelder vervollständigen aus Ihrem **persönlichen Adressbuch**, das sich automatisch aus den Personen aufbaut, an die Sie schreiben (getrennt von den organisationsweit geteilten CRM-Kontakten).

Es gibt **zwei Verfassen-Modi**:

- **Einfach** — ein schneller, hauseigener Rich-Text-Editor für alltägliche Mail von Mensch zu Mensch.
- **Vollständig** — der blockbasierte E-Mail-Builder von Owlat, wenn Sie eine gestaltete, gebrandete Nachricht möchten.

In beiden Fällen wird der Text durch dieselbe E-Mail-Pipeline gerendert (Boilerplate, CSS-Inlining, Dark-Mode-Behandlung), bevor er hinausgeht.

### Textbausteine (vorformulierte Antworten)

Textbausteine sind wiederverwendbare vorformulierte Antworten, die Sie beim Verfassen einfügen. Tippen Sie **`/`** am Zeilenanfang (oder nach einem Leerzeichen), und eine Auswahl öffnet sich, die beim Weitertippen gefiltert wird; **Enter** oder **Tab** fügt den gewählten Baustein ein, **Esc** schließt die Auswahl. Jeder Baustein kann ein kurzes **Kürzel** als Alias haben (angezeigt als `/hello`), sodass Sie direkt dorthin springen können.

Baustein-Texte dürfen einen Platzhalter **`{{firstName}}`** enthalten, der beim Einfügen aus dem Adressbuchnamen der ersten empfangenden Person aufgelöst wird (ein unbekannter Name fügt eine sichtbare Markierung `[firstName]` ein statt einer leeren Anrede). Bausteine verwalten Sie unter **Postbox → Einstellungen → Textbausteine**.

### Markdown-Tippkürzel

Der einfache Composer wandelt Markdown während des Tippens um, wie in Notion. Am Zeilenanfang macht ein nachfolgendes Leerzeichen aus `- ` oder `* ` eine Aufzählung, aus `1. ` eine nummerierte Liste, aus `# ` eine H1, aus `## ` eine H2 und aus `> ` ein Zitat. Inline werden `**bold**`, `*italic*` und `` `code` `` beim schließenden Zeichen umgewandelt. Das nächste **Rückgängig** (`Cmd/Ctrl+Z`) nach einer Umwandlung stellt den wörtlichen Markierungstext wieder her.

### Emoji-Shortcodes & Smileys

Tippen Sie **`:`** gefolgt von ein paar Buchstaben, um eine Emoji-Auswahl zu öffnen (`:smi` → 🙂); **Enter** / **Tab** fügt ein, **Esc** schließt und lässt Ihren getippten Text unberührt. Gängige ASCII-Smileys werden ebenfalls beim folgenden Leerzeichen umgewandelt — `:)`, `:(`, `:D`, `;)`, `<3` und ihre `:-)`-Varianten werden zum passenden Emoji.

### Inline-Bilder

Fügen Sie ein Bild direkt in den Nachrichtentext ein oder ziehen Sie es hinein, und es wird als `cid:`-Anhang mit Content-ID eingebettet (keine entfernte URL, sodass es bei der empfangenden Person dargestellt wird, ohne dass etwas Externes geladen wird). Bilder werden vor dem Upload clientseitig herunterskaliert; wenn Sie das Bild aus dem Text löschen, entfällt auch der Anhang. Das ist etwas anderes, als eine Datei als regulären Anhang hinzuzufügen.

### Ghost-Text-Autovervollständigung

Mit aktivem Flag **`ai`** und eingeschalteten **Schreibvorschlägen** (standardmäßig an) bietet der Composer eine eingebettete, grau dargestellte Vervollständigung, während Sie schreiben — **Tab** übernimmt sie, **Esc** oder jeder andere Tastendruck verwirft sie. Sie läuft auf einem schnellen, günstigen Modell, ist entprellt und ratenbegrenzt und zeigt nichts an, wenn das Modell unsicher ist. Sie ist beratend: Nichts wird eingefügt, bevor Sie Tab drücken. Umschalten können Sie sie unter **Postbox → Einstellungen** (siehe [Postbox-Einstellungen](/guide/postbox-settings)).

### Tonfall umschreiben

Markieren Sie im einfachen Composer ein paar Wörter (mit aktivem Flag **`ai`**), und eine schwebende Pille bietet an, die Auswahl umzuschreiben: **Kürzer**, **Freundlicher**, **Förmlicher**, **Grammatik korrigieren** oder **Übersetzen** in eine andere Sprache. Das Ergebnis wird als Vorschau **Original vs. Umgeschrieben** mit **Übernehmen** / **Verwerfen** angezeigt — nichts ändert sich, bevor Sie es übernehmen.

### Schreibstimme (in meiner Stimme schreiben)

Unter **Postbox → Einstellungen → Schreibstimme** (benötigt das Flag **`ai`**) können Sie **KI-Entwürfe personalisieren** einschalten. Owlat lernt ein schlankes Profil — Anreden, Grußformeln, Förmlichkeit, Knappheit, Sprachen, Emoji-Nutzung — aus einer Stichprobe Ihrer eigenen **gesendeten** Mail und lässt es in KI-Antwortvorschläge und Umschreibungen einfließen, damit diese nach Ihnen klingen. Es gilt **pro Postfach** und ist **standardmäßig deaktiviert**; eine Schaltfläche **Jetzt aktualisieren** lernt es neu. Es prägt nur die beratenden Entwürfe, die Sie prüfen — es versendet nie etwas.

### Geplanter Versand und Senden rückgängig machen

- **Senden rückgängig machen**: Nachdem Sie auf Senden geklickt haben, liegt die Nachricht kurz in einem Wartefenster (standardmäßig 30 Sekunden), bevor sie tatsächlich verschickt wird. Klicken Sie innerhalb des Fensters auf **Rückgängig**, und der Entwurf kehrt unverändert in den Composer zurück.
- **Geplanter Versand**: Wählen Sie ein zukünftiges Datum samt Uhrzeit, und der Entwurf wird bis dahin zurückgehalten und von einem Sicherheitsnetz-Cron verschickt, sodass er auch dann hinausgeht, wenn sonst nichts läuft.

## Mail lesen

Nachrichtentexte werden aus Sicherheitsgründen in einem Sandbox-Rahmen dargestellt. Zwei Lesehilfen:

- **Entfernte Bilder sind standardmäßig blockiert** — externe Bilder werden nicht geladen (und können nicht nach Hause funken), bis Sie in der Nachricht auf **Bilder anzeigen** klicken. Inline- und Data-URI-Bilder werden immer dargestellt.
- **Zitierter Text ist eingeklappt** — der ursprüngliche Thread, den eine Antwort zitiert, verbirgt sich hinter einem Umschalter, sodass Sie zuerst die neue Nachricht sehen und die Historie bei Bedarf ausklappen können.

### Dark-Mode-Darstellung

Wenn die App im Dark Mode läuft, passt Postbox jede empfangene HTML-Nachricht an, statt jede Mail auf eine grelle weiße Karte zu zwingen:

- **Einfache Nachrichten werden umgestaltet** — schlichte, überwiegend textliche Mail wird auf dunklem Hintergrund mit heller Schrift dargestellt, und nur kontrastarme Inline-Textfarben werden aufgehellt. Farben, die ohnehin gut lesbar sind, und jedes Element, das seinen eigenen Hintergrund setzt, bleiben unangetastet.
- **Gestaltete Nachrichten bleiben hell** — Mail, die eigenes Layout und eigene Hintergrundfarben mitbringt (Newsletter, gebrandete Vorlagen), behält ihre exakten Farben und wird als helle „Papier“-Karte auf dem dunklen Hintergrund gezeigt, sodass nichts verzerrt wird.

Ein Umschalter pro Nachricht im Leser (eine Sonne-/Mond-Schaltfläche, die nur erscheint, während die App selbst im Dark Mode ist) dreht eine einzelne Nachricht um: **Diese Nachricht auf hellem Hintergrund darstellen** / **Diese Nachricht im Dark Mode darstellen**. Die Wahl gilt pro Nachricht und wird beim Neuladen zurückgesetzt. Im Light Mode wird jede Nachricht exakt so dargestellt, wie sie gesendet wurde.

### Schnellansicht für Anhänge

Klicken Sie auf einen vorschaufähigen Anhang, um ihn in einer Lightbox in der App zu öffnen, statt ihn herunterzuladen — unterstützt werden **Bilder** und **PDFs**. Enthält eine Nachricht mehrere vorschaufähige Anhänge, zeigt die Lightbox einen Zähler „N von M“, und Sie wechseln mit den **Pfeiltasten ←/→** oder den Chevrons auf dem Bildschirm zwischen ihnen. Jede Vorschau bietet die Aktionen **In neuem Tab öffnen**, **Herunterladen** und **Schließen**; alles, was sich nicht einbetten lässt, fällt auf eine Download-Aufforderung zurück.

### Tracker- & Datenschutz-Badge

Postbox erkennt Tracking-Pixel — entfernte Bilder, die 1×1 groß, versteckt oder von einem bekannten Open-Tracker-Host ausgeliefert sind — im bereinigten Nachrichtentext. Enthält eine Nachricht solche Pixel, nennt das Banner zu blockierten Bildern die Anzahl („Bilder blockiert — N Tracking-Pixel erkannt.“), und ein Schild-Badge in der Kopfzeile öffnet ein Popover, das erklärt, was gefunden wurde.

Entscheidend ist die **zweistufige Freigabe**: Ein Klick auf **Bilder anzeigen** lädt die echten entfernten Bilder, **hält die Tracking-Pixel aber weiterhin zurück**, und ein zweites Banner erscheint („N Tracking-Pixel bleiben blockiert.“). Erst ein Klick auf **Alles laden** lädt auch die Tracker. So können Sie die echten Bilder einer Nachricht sehen, ohne dem Absender zu bestätigen, dass Sie sie geöffnet haben.

Derselbe Schutz gilt für den **KI-Agenten**: Wenn die Verarbeitungsstrecke für eingehende Mail einen Nachrichtentext als Kontext für das Modell zusammenstellt, werden entfernte Bilder und Tracking-Pixel zuvor entfernt (eingebettete `data:`-/`cid:`-Bilder bleiben erhalten), sodass der Agent, der jede eingehende Nachricht automatisch liest, nie ein entferntes Pixel auflöst und dem Absender nie ein Öffnen verrät.

### Abmeldung per Klick

Wenn eine Nachricht einen `List-Unsubscribe`-Header mitbringt, zeigt Postbox einen Chip **Abmelden**, der die sicherste verfügbare Methode nutzt:

- **RFC 8058 One-Click** (`List-Unsubscribe-Post`) — nach einer Bestätigungsabfrage sendet Owlat den standardisierten One-Click-POST **vom Server aus** (nicht aus Ihrem Browser), ausschließlich über HTTPS, mit SSRF-Schutz und ohne Weiterleitungen zu folgen. Bei Erfolg wechselt der Chip zu **Abgemeldet**.
- **Mailto** — öffnet eine vorausgefüllte Abmeldenachricht, die Sie versenden.
- **Einfacher Link** — öffnet die Abmeldeseite des Absenders in einem neuen Tab.

Schlägt die One-Click-Anfrage fehl, wird ersatzweise die Abmeldeseite geöffnet. Ein Abmelden verändert die Nachricht nie.

### Transparenz über Linkziele

Um Phishing zu erschweren, erhält jeder Link in einer empfangenen Nachricht seinen **echten Ziel-Host** als nativen Hover-Tooltip (ein vom Absender mitgelieferter Tooltip wird verworfen — er könnte lügen). Wenn der sichtbare Text eines Links nach einer Domain aussieht, aber auf eine andere zeigt, hängt Postbox eine gedämpfte Markierung **→ real-host.com** dahinter an. Bekannte Tracking-Parameter (`utm_*`, `fbclid`, `gclid`, …) werden aus Links entfernt, während der Rest der URL erhalten bleibt.

### Die Heute-Ansicht (die Startoberfläche des Postfachs)

Das Postfach öffnet sich auf **Heute** — einer fokussierten einzelnen Spalte,
die die Arbeit des Tages zeigt und sonst nichts: eine Liste **Für Sie** mit
E-Mails, die auf Ihre Antwort warten (dieselben Einträge wie in der
[Antwort-Warteschlange](/guide/reply-queue)), die heutige Mail (alles, was
seit Ihrer lokalen Mitternacht eingegangen ist, plus alles von gestern noch
Ungelesene) und ein zentriertes Element **Ältere Mails anzeigen (n)**, das
ältere Mail inline aufklappt. Mail, die die [Smart Inbox](/guide/smart-inbox)
als Newsletter, Benachrichtigung oder Beleg einordnet, überfrachtet „Heute“
nicht — eine unaufdringliche Sammelzeile („12 Newsletter & Belege automatisch
abgelegt · ansehen“) verlinkt stattdessen auf die Kategorien-Ansicht.

Eine Nachricht in „Heute“ zu öffnen hält Sie in der fokussierten Spalte: Die
Konversation erscheint in einem **zentrierten Leser** über der Liste (der
vollständige Leser — Antworten, Weiterleiten, Zurückstellen und KI-Hilfe
funktionieren dort alle). **Esc** oder ein Klick daneben bringt Sie exakt an
die Stelle der Liste zurück, an der Sie waren, **`j`**/**`k`** springen zur
nächsten oder vorherigen Konversation, ohne zu schließen, und
Archivieren/Löschen/Zurückstellen rückt automatisch zur nächsten vor (gemäß
Ihrer Einstellung zum automatischen Weiterrücken). Links auf eine bestimmte
Nachricht öffnen sich im Heute-Modus auf dieselbe Weise.

**Durchsuchen** ist die vollständige Drei-Spalten-Oberfläche (Ordnerleiste,
Liste, Leser) für Ordnerarbeit und Massentriage. Wechseln Sie mit der
Schaltfläche **Durchsuchen** in der Kopfzeile von „Heute“, drücken Sie **`b`**
(oder **Cmd/Ctrl+B**) zum Umschalten; **Esc** in „Durchsuchen“ führt zurück zu
„Heute“. **`/`** in „Heute“ springt nach „Durchsuchen“ mit fokussierter Suche.
Der zuletzt genutzte Modus wird in Ihrem Konto gespeichert. Jeder andere
Ordner und jede Suche nutzen die reguläre Drei-Spalten-Oberfläche — jede
Zeile, jedes Kürzel und jede Aktion in „Heute“ ist dieselbe wie in
„Durchsuchen“.

### Ansichtsmodi des Postfachs

Die Kopfzeile des Postfachs hat ein beschriftetes Bedienelement **Flach |
Konversationen | Kategorien** — genau ein Modus ist jeweils aktiv:

- **Flach** (Standard) — eine Zeile pro Nachricht, mit Hover- und
  `j`/`k`-Tastaturtriage.
- **Konversationen** — eine Zeile pro Thread, mit Nachrichtenanzahl und
  Ungelesen-Badge.
- **Kategorien** — die Gruppierung der [Smart Inbox](/guide/smart-inbox) in die
  Abschnitte Personen, Newsletter, Benachrichtigungen und Belege.

Ihre Wahl wird in Ihrem Konto gespeichert und folgt Ihnen daher über Geräte
und Neuladen hinweg. Die Modi gelten nur für den Posteingang — jeder andere
Ordner bleibt eine flache Liste.

### Tastenkürzel

Drücken Sie überall in Postbox **`?`** für den vollständigen Spickzettel. Das
Ein-Tasten-Vokabular funktioniert in der Nachrichtenliste (auf der fokussierten
Zeile) und beim Lesen (auf der geöffneten Nachricht) und ist wirkungslos,
sobald Sie in ein Feld tippen:

- **Navigieren**: `j`/`k` (oder Pfeiltasten) bewegen, `Enter` öffnet, `/`
  fokussiert die Suche, `b` schaltet den Posteingang zwischen „Heute“ und
  „Durchsuchen“ um (`Esc` in „Durchsuchen“ führt zurück zu „Heute“).
- **Triage**: `e` archivieren, `#` oder `Delete` in den Papierkorb, `s` mit
  Stern versehen, `u` gelesen umschalten, `Shift+U` als ungelesen markieren,
  `x` auswählen (steuert die Leiste für Sammelaktionen).
- **Organisieren**: `h` zurückstellen, `l` Label hinzufügen, `v` in Ordner
  verschieben.
- **Verfassen**: `r` antworten, `a` allen antworten, `f` weiterleiten — aus der
  Liste heraus öffnen sie die Nachricht mit bereitem Composer; im Composer
  sendet `Cmd/Ctrl+Enter` und `Cmd/Ctrl+Shift+Enter` öffnet den geplanten
  Versand.

### KI: zusammenfassen & Antworten vorschlagen

Wenn das Feature-Flag **`ai`** aktiv ist (es benötigt einen konfigurierten
LLM-Anbieter — siehe [Feature-Flags](/guide/feature-flags)), zeigt jeder
geöffnete Thread eine Schaltfläche **Zusammenfassen** (2–4 Stichpunkte) sowie
**Antworten vorschlagen** (einige versandfertige Optionen; wählen Sie eine aus,
um eine vorausgefüllte Antwort zu öffnen). Die Ausgabe ist beratend — sie wird
nie automatisch versendet, und der Thread wird als nicht vertrauenswürdige
Eingabe behandelt.

Alle nachfolgenden KI-Funktionen sind durch dasselbe Flag **`ai`** geschützt,
pro Benutzerin und Benutzer ratenbegrenzt und beratend — Owlat versendet oder
bearbeitet niemals eigenständig Mail.

### KI-Thread-Zusammenfassung

Bei einem **langen** Thread (grob ab fünf Nachrichten oder viel Text) zeigt Postbox oben einen zwischengespeicherten einzeiligen Streifen **Zusammenfassung:**; ein Klick klappt 2–4 Stichpunkte mit den Kernaussagen auf. Sie ist durch das Flag **`ai`** und die Einstellung **Lange Threads automatisch zusammenfassen** (standardmäßig an) geschützt, und die Zusammenfassung bleibt zwischengespeichert, bis eine neue Nachricht eintrifft, sodass sie nicht bei jedem Öffnen neu erzeugt wird. Sie ist fehlertolerant — ist das Modell nicht verfügbar, erscheint der Streifen einfach nicht.

### Diesen Thread befragen

Die Fußzeile des Lesers hat ein Feld **Fragen Sie zu diesem Thread…** (mit aktivem Flag **`ai`**). Stellen Sie eine Frage, und Owlat antwortet ausschließlich auf Basis der Nachrichten dieser Konversation — es ist angewiesen, das klar zu sagen, wenn der Thread die Antwort nicht enthält. Antworten sind beratend und werden nicht gespeichert.

### Chip für Terminabsichten

Wenn jemand in normaler Prosa um einen Termin bittet (ohne angehängte `.ics`-Einladung), blendet Postbox einen unaufdringlichen Chip **„Terminanfrage — Antwort entwerfen?“** ein (mit aktivem Flag **`ai`**). Klicken Sie darauf, und die KI schlägt einige versandfertige Antworten vor — eine vorgeschlagene Zeit annehmen oder eine Alternative anbieten —, die Sie dann prüfen und versenden. Sie bestätigt nie eigenständig einen Termin. Echte Kalendereinladungen werden weiterhin stattdessen als [Einladungskarte](#calendar-invites) dargestellt.

### Kalendereinladungen

Eine Nachricht mit einer Kalendereinladung (ein `text/calendar`-Teil,
einschließlich der Inline-Form, die Google Calendar und Outlook senden) wird
als **Einladungskarte** mit Zusammenfassung, Zeit, Ort und Organisation
dargestellt. **Annehmen / Vielleicht / Ablehnen** sendet eine Rückmeldung an
die organisierende Person, mit einer standardkonformen `.ics`-Datei
(`METHOD:REPLY`) im Anhang.

### Einen Absender blockieren

In einem geöffneten Thread ist **Absender blockieren** eine Ein-Klick-Aktion: Sie erzeugt einen Filter mit hoher Priorität, der alle künftige Mail von dieser Adresse nach Spam leitet (oder in den Papierkorb verschiebt, wenn das Postfach keinen Spam-Ordner hat), und verschiebt die aktuelle Nachricht nach Spam.

### Verschlüsselte & signierte Mail (PGP / S/MIME)

Postbox **erkennt** PGP- und S/MIME-Nachrichten und kennzeichnet sie
ehrlich — *Verschlüsselt (PGP)* oder *Signiert (PGP) · nicht verifiziert*.
Owlat verifiziert Signaturen noch nicht und entschlüsselt keine Inhalte, zeigt
daher auch nie ein irreführendes „verifiziert“-Häkchen; verschlüsselte Inhalte
werden gekennzeichnet statt als Kauderwelsch dargestellt, und inline
klarsignierte Nachrichten zeigen ihren lesbaren Text.

## Das Postfach abarbeiten

### Automatisches Weiterrücken nach der Triage

Wenn Sie die Konversation, die Sie gerade lesen, archivieren, löschen, zurückstellen oder als Spam markieren, bringt Postbox Sie direkt zur nächsten, statt Sie zurück in die Liste zu werfen. Das Verhalten wählen Sie unter **Postbox → Einstellungen → Nach dem Archivieren, Löschen oder Zurückstellen**: **Die nächste Konversation öffnen** (Standard), **Die vorherige Konversation öffnen** oder **Zurück zur Liste**. Es gilt in Ordneransichten (die Suchvorschau bleibt stehen) und fällt auf die Liste zurück, wenn es keine benachbarte Konversation gibt.

### Dichte & die Ordnerleiste

Zwei Layout-Steuerungen halten das Postfach so kompakt oder so großzügig, wie Sie mögen:

- **Dichte** — **Komfortabel** (der großzügige Standard) oder **Kompakt** (engere Zeilen mit einzeiligem Betreff/Auszug, im Stil von Apple Mail). Einstellbar unter **Postbox → Einstellungen → Dichte**.
- **Einklappbare Ordnerleiste** — klappen Sie die linke Ordnerleiste mit der Schaltfläche an ihrem Fuß oder mit **`Cmd/Ctrl+Shift+D`** zu einem schmalen Icon-Streifen zusammen; der eingeklappte Zustand wird pro Gerät gemerkt.

### Schnelle große Ordner

Ordner mit mehr als etwa 100 Konversationen werden mit einer **fensterbasierten Liste** dargestellt — nur die Zeilen auf dem Bildschirm werden gemountet —, sodass das Scrollen in einem großen Postfach flüssig bleibt. Darunter wird jede Zeile ganz normal gerendert.

### Rückgängig machbare Triage

Archivieren, Löschen, Verschieben oder als Spam markieren (einzeln oder als Sammelaktion) blendet einen kurzen Toast ein — „Archiviert“, „In den Papierkorb verschoben“, „Verschoben“, „Als Spam markiert“ — mit einer Schaltfläche **Rückgängig** für etwa acht Sekunden. Klicken Sie auf **Rückgängig** oder drücken Sie **`Cmd/Ctrl+Z`**, während Sie nicht tippen, um die Nachricht(en) dorthin zurückzulegen, wo sie waren.

Wie Sie das Postfach in Personen / Newsletter / Benachrichtigungen / Belege gruppieren, steht unter [Smart Inbox](/guide/smart-inbox).

## Kontakte

**Postbox → Kontakte** ist Ihr persönliches Adressbuch. Adressen, an die Sie
schreiben, werden automatisch gemerkt und speisen die Empfänger-Autovervollständigung;
auf der Kontakte-Seite können Sie Einträge suchen, hinzufügen, bearbeiten und
entfernen oder eine neue Nachricht an einen Eintrag beginnen.

## Filter

Unter **Einstellungen → Filter** legen Sie Regeln an, die auf eingehende Mail angewendet werden. Jede Regel hat eine Liste von Bedingungen (Von / An / Cc / Betreff / Text, ein eigener Header nach Name, Nachrichtengröße mit größer-als / kleiner-als sowie „hat Anhang“) und eine Liste von Aktionen: in Ordner verschieben, Label hinzufügen, als gelesen markieren, mit Stern versehen, weiterleiten an…, in den Papierkorb verschieben und verwerfen (stilles Fallenlassen). Regeln laufen der Reihe nach; Sie können sie umsortieren.

::callout{type="tip" title="Verwerfen vs. in den Papierkorb verschieben"}
**In den Papierkorb verschieben** legt die Nachricht in Ihrem Papierkorb-Ordner ab. **Verwerfen** lässt sie stillschweigend fallen — die Nachricht wird überhaupt nicht gespeichert. Nutzen Sie „Verwerfen“ für Rauschen, das Sie nie sehen wollen.
::

## Aliasse & Weiterleitung

- **Aliasse**: Adressen, die in Ihr Postfach führen. `support@yourdomain` und `hello@yourdomain` können beide im selben Posteingang landen, ohne dass es ein zweites Konto gibt.
- **Weiterleitung**: Adressen, an die Kopien hinausgehen sollen. Nützlich, um an eine externe Adresse weiterzuleiten und lokal trotzdem eine Kopie zu behalten.

Beides wird unter **Postbox → Einstellungen** konfiguriert.

## Abwesenheitsnotiz

Unter **Einstellungen → Abwesenheit** setzen Sie Betreff, Nachrichtentext und Zeitraum. Owlat antwortet für die Dauer des Zeitraums einmal pro Absender.

## Native Clients (IMAP / SMTP)

Postbox betreibt einen echten IMAP4rev1-Server (in `apps/imap`) und nimmt SMTP-Submission über den MTA entgegen. So verbinden Sie einen nativen Client:

1. Gehen Sie zu **Postbox → Einstellungen → App-Passwörter** und erzeugen Sie eines. Das Passwort wird nur einmal angezeigt; kopieren Sie es sofort.
2. Legen Sie in Ihrem Mail-Client ein Konto an mit:

   - **IMAP**: Server `mail.<your-domain>`, Port `993`, Verschlüsselung `SSL/TLS`, Benutzername `<your-mailbox-address>`, Passwort `<app-password>`
   - **SMTP**: Server `mail.<your-domain>`, Port `587` (STARTTLS), derselbe Benutzername und dasselbe App-Passwort

Sie können mehrere App-Passwörter ausstellen — eines pro Gerät — und jedes einzeln widerrufen.

::callout{type="warning" title="Geltungsbereich von App-Passwörtern"}
Ein App-Passwort authentifiziert genau ein Postfach. Es gewährt **keinen** Zugriff auf das Owlat-Dashboard, die API oder andere Postfächer. Ein Widerruf trennt die zugehörige IMAP-/SMTP-Sitzung binnen Sekunden.
::

## Suche

Die Postbox-Suche unterstützt eine Teilmenge der Gmail-Operatoren. Sie lassen sich in einer einzigen Abfrage kombinieren.

| Operator | Beispiel | Trifft auf |
|---|---|---|
| `from:` | `from:alice@acme.com` | Nachrichten von dieser Adresse |
| `to:` | `to:billing@yourdomain` | Nachrichten an diese Adresse |
| `subject:` | `subject:invoice` | Betreff enthält diesen Text |
| `has:attachment` | `has:attachment` | Hat mindestens einen Anhang |
| `has:no-attachment` | `has:no-attachment` | Keine Anhänge (ein einzelnes Token mit Bindestrich) |
| `is:unread` | `is:unread` | Noch nicht als gelesen markiert |
| `is:read` | `is:read` | Als gelesen markiert |
| `is:starred` | `is:starred` | Markiert / mit Stern versehen |
| `in:` | `in:trash`, `in:sent`, `in:spam` | In einem bestimmten Systemordner |
| `label:` | `label:newsletters` | Hat ein bestimmtes eigenes Label |
| `before:` | `before:2026-04-01` | Vor einem Datum empfangen (YYYY-MM-DD) |
| `after:` | `after:2026-01-01` | Nach einem Datum empfangen |
| `older_than:` | `older_than:7d` | Älter als N Tage (auch `h` Stunden, `m` Minuten) |
| `newer_than:` | `newer_than:30d` | Neuer als N Tage (auch `h`, `m`) |

Einfache Wörter treffen auf Betreff, Text, Absender und Empfänger. Setzen Sie Phrasen für eine exakte Übereinstimmung in Anführungszeichen: `"quarterly review"`.

## Zurückstellen (Snooze)

Öffnen Sie einen beliebigen Thread und klicken Sie auf das Snooze-Symbol. Wählen Sie ein Datum, und der Thread verschwindet bis dahin aus dem Posteingang — zu diesem Zeitpunkt taucht er unverändert wieder ganz oben auf.

## Wie Postbox mit anderen Owlat-Funktionen zusammenhängt

| | Postbox | Team-Postfach | Marketing |
|---|---|---|---|
| **Flag** | `postbox` | `inbox` | `campaigns` / `automations` / `transactional` |
| **Postfach pro Benutzer** | Ja | Nein (gemeinsam) | entfällt |
| **IMAP/SMTP** | Ja | Nein | Nein |
| **Ausgehend** | Eins-zu-eins-Mail | Antworten | Massenversand + ausgelöst |
| **Empfängt MX-Mail** | Ja (eigene Aliasse) | Ja (gemeinsame Adressen) | Nein |
| **Threading** | Ja | Ja | entfällt |

Sie können jede Kombination betreiben — Postbox allein, Marketing allein, beides zusammen. Es gibt keine Vorgabe, das eine vor dem anderen zu aktivieren.

Ein **verbundenes externes Postfach** (`mail.external`) ist eine dritte Option, die sich neben die Spalte des gehosteten Postbox stellt: Es erscheint in derselben Webmail-Oberfläche, aber eingehende Mail wird von Ihrem eigenen Anbieter zugestellt und ausgehende Mail von ihm versendet, sodass es weder MX-Einträge noch eine verifizierte Versanddomain bei Owlat benötigt.

## Offline & lokaler Cache

Postbox kann eine kleine, schreibgeschützte Kopie der jüngsten Mail auf dem aktuellen Gerät vorhalten, sodass das Postfach nach einem Kaltstart sofort öffnet und auch ohne Verbindung lesbar bleibt.

- **Was gespeichert wird:** die neuesten rund 200 Posteingangszeilen und die bereinigten Texte der etwa 50 zuletzt gelesenen Nachrichten, jeweils dem Postfach zugeordnet, das sie zwischengespeichert hat. Zwischengespeichert wird nur die bereits bereinigte Fassung jeder Nachricht — nie die Rohmail.
- **Wo:** in der lokalen Browser-Datenbank dieses Geräts (IndexedDB). Sie ist gerätelokal und wird nie zwischen Geräten oder zum Server synchronisiert.
- **Kaltstart:** das Postfach und jede zwischengespeicherte Nachricht werden sofort aus dem Cache dargestellt, mit einem dezenten Hinweis „wird aktualisiert…“, und werden in dem Moment an Ort und Stelle abgeglichen, in dem die Live-Daten eintreffen (Live-Daten gewinnen immer).
- **Offline:** ein unaufdringliches Banner erscheint, die zwischengespeicherte Liste und die zwischengespeicherten Texte bleiben lesbar, und Aktionen, die den Server brauchen, werden mit klaren Hinweisen pausiert.
- **Steuerung:** schalten Sie **Jüngste Mail auf diesem Gerät speichern** um und nutzen Sie **Lokalen Cache leeren** unter **Postbox → Einstellungen → Auf diesem Gerät**. In der Desktop-App ist die Funktion standardmäßig an, im Browser standardmäßig aus. Lassen Sie sie auf gemeinsam genutzten Rechnern ausgeschaltet — der Cache ist unverschlüsselter lokaler Speicher. Geht dem Gerät der Speicher aus, deaktiviert sich das Zwischenspeichern stillschweigend selbst und weist in den Einstellungen darauf hin.

In dieser Version noch nicht zwischengespeichert: die Ordnerleiste (sie wird bei einem Kaltstart weiterhin aus der Live-Abfrage gerendert), Senden im Offline-Betrieb bzw. eingereihte Aktionen, die Synchronisierung des vollständigen Postfachs sowie die Verschlüsselung im Ruhezustand. Diese Punkte sind als Folgearbeiten geplant.

## Grenzen & Datenschutz

- Postfächer liegen im selben Convex-Deployment wie Ihre übrigen Daten. Sie werden nicht mit anderen Mandanten geteilt.
- Der optionale Lese-Cache auf dem Gerät (siehe oben) speichert bereinigte jüngste Mail unverschlüsselt in der lokalen Datenbank des Geräts; im Browser ist er standardmäßig aus und kann jederzeit geleert werden.
- Der MTA begrenzt die Submission-Größe pro Nachricht und die Nutzung des Verbindungspools und ratenbegrenzt den IMAP-Authentifizierungsendpunkt (fehlgeschlagene Anmeldungen werden verzögert) (siehe [Selbst hosten → Produktion](/developer/self-hosting-production)).
- Die Spamfilterung eingehender Mail nutzt denselben Inhaltsscanner, der auch Kampagnen schützt (Flag `scan.content`).
- Dateianhänge werden von ClamAV geprüft, wenn `scan.files` aktiv ist.

## Fehlerbehebung

**Ich sehe „Postbox“ nicht in der Seitenleiste.** Das Flag ist noch nicht aktiv. Schalten Sie es unter **Einstellungen → Features** oder mit `owlat-setup feature postbox on` ein und starten Sie den Stack neu.

**IMAP meldet „auth failed“.** Vergewissern Sie sich, dass Sie ein App-Passwort verwenden und nicht Ihr Dashboard-Passwort. App-Passwörter sind an genau eine Postfachadresse gebunden — verwenden Sie diese Adresse als Benutzernamen.

**Ausgehende Mail bounct.** Die Versanddomain ist noch nicht verifiziert. Öffnen Sie **Einstellungen → Domains**, fügen Sie die Domain hinzu und tragen Sie die angezeigten DNS-Einträge ein.

**Ein nativer Client erreicht den IMAP-Server nicht.** Prüfen Sie, ob Port 993 auf dem Host veröffentlicht ist und ob `IMAP_GREETING_HOST` auf denselben Hostnamen auflöst, für den Ihr TLS-Zertifikat ausgestellt wurde.

**Mein externes Postfach zeigt „Authentifizierung fehlgeschlagen“.** Geben Sie das Passwort unter **Einstellungen → Externes Postfach → Zugangsdaten aktualisieren** erneut ein. Gmail und Outlook benötigen ein App-Passwort bei aktivierter Zwei-Faktor-Authentifizierung — Ihr normales Kontopasswort funktioniert nicht. Außerdem müssen das Flag `mail.external` (und sein Docker-Profil `external-mail` bzw. der mail-sync-Worker) laufen.

Tiefere Architekturdetails (Schema, IMAP-Befehlsfluss, MTA-Integration) finden Sie unter [Postbox-Architektur](/developer/postbox-architecture).

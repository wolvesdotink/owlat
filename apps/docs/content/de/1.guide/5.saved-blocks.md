title: "Gespeicherte Blöcke"
description: "Erstellen Sie wiederverwendbare, verknüpfte Inhaltsblöcke, die Sie in jede E-Mail einsetzen können — bearbeiten Sie einen, und jede E-Mail, die ihn verwendet, aktualisiert sich automatisch."
---

Mit gespeicherten Blöcken bauen Sie wiederverwendbare Inhaltsabschnitte — einen Header, einen Footer, einen Call-to-Action — einmal auf und fügen sie in jede beliebige E-Mail ein. Anders als ein per Kopieren und Einfügen dupliziertes Schnipsel bleibt ein gespeicherter Block **verknüpft**: Bearbeiten Sie den Block, aktualisiert sich jede E-Mail, die ihn verwendet, entsprechend. Ändern Sie Ihren Footer an einer Stelle, und jede Vorlage und jede transaktionale E-Mail, die ihn trägt, wird mit der neuen Version neu gerendert.

## Warum gespeicherte Blöcke

- **Konsistenz** — Ihr Marken-Header und -Footer sehen in jeder E-Mail identisch aus.
- **Tempo** — setzen Sie einen ausgefeilten CTA-Abschnitt in Sekunden ein, statt ihn neu zu bauen.
- **Pflege mit einer einzigen Bearbeitung** — weil eingefügte Blöcke verknüpft sind, wirkt sich ein korrigierter Tippfehler oder ein ausgetauschtes Logo in einem gespeicherten Block auf jede E-Mail aus, die ihn verwendet. Kein Durchsuchen alter Vorlagen.

## Wie verknüpfte Blöcke funktionieren

Wenn Sie einen gespeicherten Block in eine E-Mail einfügen, fügt der Editor keine statische Kopie ein — er fügt eine **verknüpfte Instanz** ein. Jede Instanz merkt sich, aus welchem gespeicherten Block sie stammt, und der Editor kennzeichnet sie oberhalb des Inhalts mit dem Label **Verknüpfter Block** (das den Namen des Blocks trägt).

Was das in der Praxis bedeutet:

| Wenn Sie … | Was passiert |
| --- | --- |
| den **Inhalt** eines gespeicherten Blocks bearbeiten | Jede Vorlage und jede transaktionale E-Mail, die ihn verwendet, wird aktualisiert und passend neu gerendert. |
| einen gespeicherten Block umbenennen | Das an jeder verknüpften Instanz angezeigte Label wird auf den neuen Namen aktualisiert. |
| einen gespeicherten Block löschen | Er wird von jeder E-Mail abgekoppelt, die ihn verwendet — diese E-Mails behalten den Inhalt als normalen, nun eigenständigen Block. |
| eine verknüpfte Instanz abkoppeln | Genau diese eine E-Mail erhält eine eigenständige Kopie und empfängt keine Aktualisierungen aus der Bibliothek mehr. |

::callout{type="warning" title="Änderungen wirken sich fort"}
Den Inhalt eines gespeicherten Blocks zu bearbeiten verändert jede E-Mail, die ihn bereits verwendet. Genau darum geht es bei gespeicherten Blöcken — es bedeutet aber auch, dass eine unbedachte Änderung produktive Vorlagen verändern kann. Wenn Sie eine einmalige Abwandlung möchten, **koppeln** Sie die Instanz zuerst **ab** (siehe unten), damit Ihre Änderung lokal bleibt.
::

Das erneute Rendern der verwendenden E-Mails läuft im Hintergrund. Nachdem Sie eine Inhaltsänderung gespeichert haben, werden die betroffenen Vorlagen und transaktionalen E-Mails als veraltet markiert und kurz darauf von einem Render-Pool mit Wiederholungen neu gerendert — es kann also einen Moment dauern, bis das gerenderte HTML einer E-Mail nachgezogen ist.

## Einen Block speichern

Gespeicherte Blöcke werden auf der Seite **Mail > Blöcke** angelegt und bearbeitet.

::steps

### Die Seite „Blöcke“ öffnen

Gehen Sie zu **Mail > Blöcke** und klicken Sie auf **Neuer Block**.

### Benennen

Geben Sie dem Block einen aussagekräftigen **Namen** (z. B. „Standard-E-Mail-Header“ oder „Produkt-CTA mit Bild“) und optional eine **Beschreibung**. Die Beschreibung hilft Ihnen und Ihren Teamkolleginnen und -kollegen, später den richtigen Block auszuwählen.

### Den Inhalt aufbauen

Klicken Sie auf **Block erstellen** — damit wird der Block angelegt und ein eigener Block-Editor geöffnet, in dem Sie seinen Inhalt hinzufügen und anordnen. Der gespeicherte Block kann ein einzelner Block oder eine Gruppe mehrerer Blöcke sein. Ihre Änderungen sind der Inhalt des Blocks.

::

Ein gespeicherter Block kann einen Block oder viele enthalten. Gruppen aus mehreren Blöcken zeigen auf der Seite „Blöcke“ ein kleines Badge **N Blöcke**, sodass Sie sie auf einen Blick unterscheiden können.

## Einen gespeicherten Block einfügen

Gespeicherte Blöcke fügen Sie aus dem [E-Mail-Editor](/guide/email-editor) heraus über das Slash-Menü ein.

::steps

### Das Slash-Menü öffnen

Tippen Sie `/` an der Stelle, an der der Block stehen soll.

### Ihren Block finden

Scrollen Sie zur Gruppe **Gespeichert** am Ende des Menüs oder tippen Sie einen Teil des Blocknamens, um die Liste zu filtern.

### Ihn einfügen

Wählen Sie den Block aus. Er wird als verknüpfte Instanz direkt nach dem Block eingefügt, in dem Sie sich befinden (oder am Ende des Dokuments), gekennzeichnet mit seinem Label **Verknüpfter Block**.

::

::callout{type="info" title="Eine verknüpfte Instanz abkoppeln"}
Um eine verknüpfte Instanz in eine eigenständige Kopie zu verwandeln, klicken Sie auf das Symbol **Abkoppeln** an ihrem Label **Verknüpfter Block** und bestätigen Sie. Der abgekoppelte Block behält seinen aktuellen Inhalt, empfängt aber keine Aktualisierungen mehr aus der Bibliothek der gespeicherten Blöcke.
::

## Gespeicherte Blöcke verwalten

Öffnen Sie **Mail > Blöcke**, um jeden gespeicherten Block zu sehen. Sie können nach Name oder Beschreibung suchen und nach **Neueste**, **Am häufigsten verwendet** oder **Name (A-Z)** sortieren. Jeder Block zeigt seine **Verwendungsanzahl** (wie viele E-Mails ihn derzeit verknüpfen) und, bei Gruppen aus mehreren Blöcken, ein Badge **N Blöcke**.

Pro Block können Sie:

- **Inhalt bearbeiten** — den Block-Editor öffnen, um zu ändern, was darin steht (das ist die Bearbeitung, die sich auf jede verknüpfte E-Mail fortpflanzt).
- **Einstellungen** — den Block umbenennen oder seine Beschreibung aktualisieren.
- **Duplizieren** — eine eigenständige Kopie anlegen (benannt „… (Kopie)“), die Sie als Ausgangspunkt verwenden.
- **Löschen** — den Block aus der Bibliothek entfernen.

::callout{type="warning" title="Einen verwendeten Block löschen"}
Wenn Sie einen gespeicherten Block löschen, der von einer oder mehreren E-Mails verwendet wird, werden Sie vorher gewarnt. Beim Löschen wird der Block von jeder E-Mail **abgekoppelt**, die ihn verwendet: Diese E-Mails behalten den Inhalt als eigenständigen Block, er ist dann aber mit nichts mehr verknüpft.
::

## Bewährte Vorgehensweisen

- **Speichern Sie Header und Footer früh** — das sind die Blöcke, die Sie am häufigsten wiederverwenden; richten Sie sie daher ein, bevor Sie Ihre erste Kampagne bauen. Bearbeiten Sie sie einmal, und jede E-Mail aktualisiert sich.
- **Halten Sie Blöcke fokussiert** — ein „Header“-Block sollte nur der Header sein, nicht der Header plus der erste Inhaltsabschnitt. Kleinere Blöcke sind vielseitiger.
- **Benennen Sie Blöcke aussagekräftig** — „Weihnachtsaktion-CTA (Rot)“ ist besser als „CTA 2“. Der Name ist außerdem das, was an jeder verknüpften Instanz im Editor erscheint.
- **Koppeln Sie vor dem Anpassen ab** — wenn eine E-Mail eine abgewandelte Version eines gemeinsam genutzten Blocks braucht, koppeln Sie diese Instanz zuerst ab, damit sich Ihre Änderung nicht auf alle anderen fortpflanzt.
- **Prüfen Sie regelmäßig** — nutzen Sie die Sortierung **Am häufigsten verwendet** und die Verwendungsanzahl, um ungenutzte Blöcke zu finden, und löschen Sie sie, damit die Bibliothek aufgeräumt bleibt.

Eine Kampagne ist ein einmaliger oder geplanter E-Mail-Versand an genau ein Thema oder ein Segment. Ob Sie einen Produktstart ankündigen, einen Newsletter verschicken oder eine Aktion durchführen — der Kampagnen-Assistent führt Sie in einer festen Reihenfolge durch drei Schritte: **Einrichtung → Inhalt → Prüfen**. A/B-Tests sind ein optionaler Aufklapp-Bereich innerhalb des Schritts „Einrichtung“, sodass eine einfache Kampagne damit nie in Berührung kommt.

## Voraussetzungen

Bevor Sie eine Kampagne erstellen, sollten Sie Folgendes bereithalten:

- Eine **verifizierte Versanddomain** unter **Einstellungen > Domains** (Ihre Absenderadresse muss sie verwenden, sonst wird der Versand blockiert)
- Mindestens ein **Thema** mit Abonnenten oder ein **gespeichertes Segment** als Zielgruppe
- Optional eine bestehende **Marketing-E-Mail-Vorlage** — oder Sie lassen den Assistenten eine neue für Sie anlegen

::callout{type="info"}
Eine Kampagne adressiert immer **genau eine** Zielgruppe: ein Thema **oder** ein Segment. Es gibt weder eine Option „alle Abonnenten“ noch eine Möglichkeit, Zielgruppen zu kombinieren. Um eine breitere Gruppe zu erreichen, erstellen Sie zunächst ein Segment.
::

## Schritt für Schritt

::steps

### Neue Kampagne starten

Öffnen Sie **Kampagnen** in der Seitenleiste des Dashboards und klicken Sie oben rechts auf **Neue Kampagne**. Damit öffnet sich der dreistufige Assistent.

### Einrichtung

Der Assistent startet mit dem Schritt **Einrichtung**, der Absenderangaben und Zielgruppe auf einem Bildschirm zusammenführt.

Füllen Sie die Absenderangaben aus:

| Feld | Pflichtfeld | Hinweise |
| --- | --- | --- |
| **Kampagnenname** | Ja | Nur eine interne Bezeichnung — Empfänger sehen sie nie (z. B. „Sommer-Newsletter 2026“). |
| **Absendername** | Ja | Der Name, den Empfänger in ihrem Posteingang sehen (z. B. „John von Acme Inc“). |
| **Absender-E-Mail** | Ja | Die Adresse, von der die Kampagne versendet wird. Ihre Domain muss verifiziert sein. |
| **Antwortadresse (Reply-to)** | Nein | Wohin Antworten gehen. Leer lassen, um die Absender-E-Mail zu verwenden. |

Während Sie die **Absender-E-Mail** eingeben, prüft Owlat den Verifizierungsstatus der Domain. Ist die Domain nicht registriert oder nicht verifiziert, erscheint eine Warnung — Sie können weiter bearbeiten, aber **der Versand bleibt gesperrt, bis die Domain unter Einstellungen > Domains verifiziert ist**.

Wählen Sie anschließend **genau eine** Zielgruppe:

- **Bestimmtes Thema** — Versand an Kontakte, die ein Thema abonniert haben. Kontakte ohne E-Mail-Adresse, mit Abmeldung oder Sperre sowie Kontakte ohne abgeschlossenes Double-Opt-in werden automatisch ausgeschlossen.
- **Gespeichertes Segment** — Versand an alle Kontakte, die den Kriterien eines gespeicherten Segments entsprechen.

Owlat zeigt für Ihre Auswahl eine **geschätzte Anzahl berechtigter Empfänger** an. Bei einem Thema erfahren Sie zusätzlich, wie viele Kontakte ausgeschlossen werden und warum.

::callout{type="warning" title="Segment-Zielgruppen unterscheiden sich von Themen"}
Ein Segment adressiert **alle** passenden Kontakte unabhängig vom Themen-Abonnement, und manche haben das Double-Opt-in möglicherweise nicht abgeschlossen. Da es kein konkretes Thema zum Verlassen gibt, verzichten Segment-Versände auf den Abmeldelink im E-Mail-Text — ein `List-Unsubscribe`-Header wird jedoch weiterhin gesetzt, sodass Mail-Clients eine Ein-Klick-Abmeldung anbieten können (die den Kontakt aus allen Themen entfernt). Bevorzugen Sie eine Themen-Zielgruppe, wenn Sie vollständiges Opt-in und eine Abmeldung im E-Mail-Text benötigen.
::

**A/B-Test hinzufügen (optional).** Am Ende des Schritts „Einrichtung“ öffnet ein unauffälliger Link **A/B-Test hinzufügen** eine eingebettete Konfiguration. Lassen Sie ihn geschlossen, um eine einzige Version zu versenden; öffnen Sie ihn, um Ihre Kampagne als Split-Test zu fahren:

| Einstellung | Optionen |
| --- | --- |
| **Testart** | Betreffzeile (gleicher Inhalt, unterschiedliche Betreffe) oder E-Mail-Inhalt (zwei verschiedene Vorlagen). |
| **Aufteilung in Prozent** | 10–50 % — jede Variante geht an diesen Anteil der Zielgruppe; die Gewinnervariante geht an den Rest. |
| **Gewinnerkriterium** | Beste Öffnungsrate, beste Klickrate oder manuelle Auswahl. |
| **Testdauer** | 1–24 Stunden, bevor die Gewinnervariante automatisch bestimmt wird (wird bei manueller Auswahl nicht angezeigt). |

Betreffzeile und Vorlage von Variante A sind die, die Sie im Schritt **Inhalt** festlegen — Sie können den Test also jetzt hinzufügen und die E-Mail anschließend fertigstellen.

### Inhalt

Wählen Sie die E-Mail aus, die diese Kampagne versendet, und legen Sie dann den Betreff fest:

- **Bestehende Marketing-E-Mail verwenden** — wählen Sie aus Ihren gespeicherten Marketing-Vorlagen (Suche nach Name oder Betreff). Die Vorlage wird mit der Kampagne **verknüpft**; Ihre Originalvorlage wird referenziert, nicht kopiert.
- **Neue Marketing-E-Mail-Vorlage erstellen** — vergeben Sie einen Namen, und Owlat legt beim Fortfahren einen frischen Entwurf einer Marketing-Vorlage an, der mit dieser Kampagne verknüpft ist.

Geben Sie anschließend den **E-Mail-Betreff** ein (Pflichtfeld). In diesem Schritt erscheinen ausschließlich Vorlagen vom Typ **Marketing** — transaktionale Vorlagen werden nicht aufgeführt.

::callout{type="info"}
Sie können den Inhalt der verknüpften E-Mail auch nach dem Erstellen der Kampagne bearbeiten. Die detaillierte visuelle Gestaltung findet im E-Mail-Editor statt, nicht in diesem Assistenten.
::

### Prüfen & Senden

Der letzte Schritt fasst alles zusammen — Kampagnenname, Absenderangaben, Zielgruppe, E-Mail-Inhalt und eine eventuelle A/B-Test-Konfiguration. Jeder Abschnitt hat ein Stiftsymbol, mit dem Sie zurückspringen und bearbeiten können.

**Senden Sie zuerst einen Test.** Nutzen Sie **Test-E-Mail senden**, um eine echte Kopie der Kampagne an die Adresse eines Ihrer eigenen Teammitglieder zuzustellen, bevor Sie tatsächlich versenden.

Wählen Sie dann den Versandzeitpunkt:

- **Jetzt senden** — die Zustellung an alle berechtigten Empfänger beginnt sofort.
- **Für später planen** — wählen Sie Datum und Uhrzeit. Optional aktivieren Sie **Zur Ortszeit des Empfängers senden**, um zur gewählten Uhrzeit in der jeweiligen Zeitzone des Kontakts zuzustellen (Kontakte ohne Zeitzone erhalten die E-Mail zu Ihrer gewählten Zeit).

Ist die Domain der Absender-E-Mail nicht verifiziert, ist die Senden-Schaltfläche deaktiviert und der Grund wird angezeigt. Nach Ihrer Bestätigung stellt Owlat die Kampagne in die Warteschlange oder plant sie ein und bringt Sie zurück zur Kampagnenliste.

::

## Test-E-Mail senden

Klicken Sie im Schritt **Prüfen** auf **Test senden** und geben Sie die Adresse ein. Owlat versendet eine echte, vollständig gerenderte Kopie der Kampagnen-E-Mail — mit derselben Engine wie beim Live-Versand —, sodass Sie Links, Bilder und Personalisierung im eigenen Posteingang prüfen können.

::callout{type="info"}
Aus Sicherheitsgründen können Test-E-Mails nur an Adressen gesendet werden, die zu den eigenen Teammitgliedern Ihrer Organisation gehören — nicht an beliebige externe Adressen. Testversände sind außerdem pro Benutzer ratenbegrenzt.
::

::callout{type="warning"}
Senden Sie sich vor dem echten Versand immer einen Test. Der Kampagnen-Assistent bietet keine In-App-Vorschau des Renderings; die Test-E-Mail ist der Weg, das Erscheinungsbild zu bestätigen. Die detaillierte visuelle Bearbeitung findet im E-Mail-Editor statt.
::

## Tipps für bessere Kampagnen

- **Betreff personalisieren** — Variablen wie `{{firstName}}` im E-Mail-Betreff können die Öffnungsrate steigern.
- **Betreffzeilen kurz halten** — unter etwa 50 Zeichen liest sich besser auf Mobilgeräten.
- **Gezielt A/B-testen** — beginnen Sie mit Betreffzeilen-Tests; sie sind am einfachsten zu interpretieren.
- **Für Relevanz segmentieren** — zielgerichtete Inhalte an eine fokussierte Gruppe schlagen den Rundumschlag an alle.

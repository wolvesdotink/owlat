Owlat ist eine E-Mail-Plattform für Teams, die Marketing-Kampagnen, transaktionale E-Mails und automatisierte Workflows versenden müssen — alles an einem Ort. Dieser Guide führt Sie durch die Einrichtung Ihres Workspace und den Versand Ihrer ersten E-Mail.

::callout{type="info" title="Jede Owlat-Installation ist heute selbst gehostet"}
Owlat ist derzeit **ausschließlich selbst gehostet** — Sie betreiben es auf Ihrem eigenen VPS. Eine verwaltete Cloud steht auf der Roadmap; [tragen Sie sich in die Warteliste ein](https://owlat.app/waitlist), um zum Start benachrichtigt zu werden. Falls Sie bereits eine Owlat-Instanz eingerichtet haben, springen Sie zu [Schritt 1](#1-set-up-your-workspace) weiter unten.
::

## 0. Owlat bereitstellen

Auf einem frischen Linux-VPS mit installiertem Docker und Docker Compose v2 genügt ein einziger Befehl:

```sh
curl -fsSL https://get.owlat.app | bash
```

Der interaktive Assistent fragt nach Ihrer Sendedomain (EHLO-Hostname und Bounce-/Return-Path-Domain), Ihrem E-Mail-Sendeanbieter (eingebauter MTA, Resend oder SES), den API-Schlüsseln für KI-Anbieter sowie einem Administratorkonto und schreibt anschließend Ihre Konfiguration. DKIM-Schlüssel werden für Sie erzeugt; die daraus resultierenden DNS-Einträge fügen Sie danach hinzu. Der vollständige Deployment-Guide findet sich unter [Self-Hosting](/developer/self-hosting).

Sobald Ihre Instanz läuft, öffnen Sie sie im Browser und fahren unten fort.

## Was Sie mit Owlat tun können

- **Ansprechende E-Mails gestalten** mit einem visuellen, blockbasierten [Editor](/guide/email-editor), der in jedem E-Mail-Client konsistent rendert
- **Ihre Zielgruppe verwalten** mit [Kontakten](/guide/contacts), [Themen](/guide/topics), [Segmenten](/guide/segments) und [eigenen Eigenschaften](/guide/contact-properties)
- **Kampagnen versenden** mit [Auswertung](/guide/campaigns), [A/B-Tests](/guide/ab-testing) und Zeitplanung
- **Workflows automatisieren** mit triggerbasierten [Automationen](/guide/automations), die von selbst laufen
- **Transaktionale E-Mails versenden** wie Passwort-Resets und Bestellbestätigungen über die [API](/guide/transactional)
- **Ihre Absenderreputation schützen** mit [Domain-Verifizierung](/guide/deliverability), Sperrlistenverwaltung und Compliance-Kontrollen

::callout{type="tip" title="Onboarding-Checkliste"}
Bei der ersten Anmeldung enthält das Dashboard eine Onboarding-Checkliste, die Ihren Einrichtungsfortschritt festhält — Domain-Verifizierung, erste Vorlage, erste Kampagne und mehr. Folgen Sie ihr für einen geführten Weg zum ersten Versand.
::

## 1. Workspace einrichten

Jedes Owlat-Deployment beherbergt genau eine Organisation, die beim Deployment angelegt wird — Sie erstellen sie nicht selbst.

1. Melden Sie sich mit dem Administratorkonto an, das Sie im Einrichtungsassistenten (`owlat quickstart`) erstellt haben.
2. Öffnen Sie **Einstellungen > Organisation**, um Ihre Organisationsdaten zu bestätigen.
3. Laden Sie Ihr Team unter **Einstellungen > Organisation > Teammitglieder** ein und weisen Sie [Rollen](/guide/team-permissions) zu.

## 2. Eine Sendedomain verifizieren

::callout{type="info" title="Nur wenn Sie Marketing- oder transaktionale E-Mails versenden"}
Eine Domain zu verifizieren und einen Zustellanbieter zu konfigurieren ist erforderlich, wenn Sie **Kampagnen, transaktionale E-Mails oder Automationen** versenden. Wenn Sie lediglich Mail aus einem externen Postfach über IMAP lesen (und 1:1 über Ihr eigenes SMTP antworten) möchten, können Sie diesen Schritt überspringen — siehe [Betriebsmodi](/guide/operating-modes) für das Gesamtbild.
::

Bevor Sie Marketing- oder transaktionale E-Mails versenden können, müssen Sie nachweisen, dass Ihnen Ihre Sendedomain gehört.

1. Gehen Sie zu **Einstellungen > Technik > Sendedomains**.
2. Fügen Sie Ihre Sendedomain hinzu.
3. Tragen Sie die erforderlichen DNS-Einträge (SPF, DKIM, DMARC) bei Ihrem DNS-Anbieter ein.
4. Klicken Sie auf **Verifizieren** und warten Sie auf die Bestätigung.

Eine ausführliche Anleitung und die Erklärung jedes DNS-Eintrags finden Sie unter [Zustellbarkeit](/guide/deliverability).

## 3. Zielgruppe aufbauen

1. Gehen Sie zu **Zielgruppe > Kontakte** und [importieren Sie Ihre Kontakte](/guide/contacts) per CSV oder legen Sie sie manuell an.
2. Erstellen Sie [Themen](/guide/topics), um Ihre Zielgruppe in ansprechbare Gruppen zu gliedern.
3. Definieren Sie [Kontakteigenschaften](/guide/contact-properties) unter **Einstellungen > Eigenschaften** für eigene Datenfelder.
4. Bauen Sie [Segmente](/guide/segments), um dynamische, regelbasierte Zielgruppen zu erzeugen.
5. Richten Sie [Formulare](/guide/forms) ein, um neue Anmeldungen von Ihrer Website zu erfassen.

## 4. E-Mail-Bausteine anlegen

1. Richten Sie Ihr [E-Mail-Theme](/guide/email-theme) unter **Einstellungen > Organisation > E-Mail-Theme** für ein einheitliches Branding ein.
2. Erstellen Sie Marketing-Vorlagen unter **Mail > Marketing** mit dem [E-Mail-Editor](/guide/email-editor).
3. Speichern Sie wiederverwendbare Abschnitte als [Gespeicherte Blöcke](/guide/saved-blocks) unter **Mail > Blöcke**.
4. Erstellen Sie transaktionale Vorlagen unter **Mail > Transaktional** für per API ausgelöste E-Mails.
5. Fügen Sie [Übersetzungen](/guide/translations) für mehrsprachige Zielgruppen hinzu.

## 5. Erste Kampagne versenden

1. Öffnen Sie **Kampagnen > Alle Kampagnen** und klicken Sie auf **Neue Kampagne**.
2. **Einrichtung** — benennen Sie Ihre Kampagne, legen Sie den Absender fest (Absendername und Absenderadresse) und wählen Sie ein einzelnes [Thema](/guide/topics) oder ein einzelnes [Segment](/guide/segments). Optional öffnen Sie **A/B-Test hinzufügen**, um einen Betreff- oder Inhaltstest einzurichten.
3. **Inhalt** — schreiben Sie Ihre Betreffzeile und wählen Sie die zu versendende Vorlage.
4. **Prüfen** — bestätigen Sie die Angaben und versenden Sie sofort oder planen Sie den Versand für später.

Eine ausführliche Anleitung finden Sie unter [Kampagnen & Auswertung](/guide/campaigns), zur Optimierung Ihrer Sendungen unter [A/B-Tests](/guide/ab-testing).

## 6. Automationen einrichten

1. Gehen Sie zu **Automationen** und erstellen Sie eine neue Automation.
2. Konfigurieren Sie einen Trigger (neuer Kontakt, Kontakt aktualisiert, benutzerdefiniertes Event, Themenabonnement).
3. Fügen Sie Schritte hinzu: E-Mail senden, warten, nach Bedingungen verzweigen.
4. Aktivieren und überwachen.

Gängige Muster und eine vollständige Bauanleitung finden Sie unter [Automationen](/guide/automations).

## 7. Ihre Anwendung anbinden

Integrieren Sie Owlat in Ihr Produkt, um Kontakte zu synchronisieren, transaktionale E-Mails zu versenden und eigene Events zu erfassen. Erstellen Sie einen API-Schlüssel unter **Einstellungen > Technik > API-Schlüssel** und sehen Sie in der [API-Dokumentation](/api) nach Endpunkten und SDK-Optionen.

Richten Sie [Webhooks](/guide/api-keys-webhooks) ein, um Echtzeit-Benachrichtigungen über Zustellereignisse, Interaktionen und mehr zu erhalten.

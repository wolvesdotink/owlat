title: "Medienbibliothek"
description: "Bilder und Dateien für Ihre E-Mails an einem zentralen Ort verwalten, organisieren, durchsuchen und wiederverwenden."
---

Die Medienbibliothek ist ein zentraler Ort für die Verwaltung von Bildern und Dateien, die in Ihren E-Mails verwendet werden. Statt Bilder jedes Mal einzeln hochzuladen, organisieren, durchsuchen und verwenden Sie Assets von einer Stelle aus wieder.

## Zur Medienbibliothek navigieren

Öffnen Sie **Mail > Medien** in der Seitenleiste des Dashboards. Die Medienbibliothek zeigt alle hochgeladenen Assets mit Vorschaubildern, Dateinamen und Metadaten.

## Dateien hochladen

Sie können Dateien auf zwei Wegen zur Bibliothek hinzufügen:

- **Drag & Drop** — ziehen Sie eine oder mehrere Dateien direkt auf die Seite der Medienbibliothek
- **Upload-Schaltfläche** — klicken Sie auf **Hochladen** und wählen Sie Dateien von Ihrem Computer aus

Der Upload der Medienbibliothek akzeptiert gängige Bildformate (JPEG, PNG, GIF, WebP, SVG), PDF sowie Video- und Audiodateien. Weitere Dokumenttypen (Word, Excel, CSV und Ähnliches) lassen sich ausschließlich über die [Transaktionale API](/api/transactional) anhängen, nicht über den Upload-Dialog im Dashboard.

## Suchen und filtern

Nutzen Sie die Suchleiste, um Assets nach Dateiname, Alt-Text oder Tags zu finden. Je größer Ihre Bibliothek wird, desto nützlicher werden Tags, um Assets nach Kampagne, Produkt oder Inhaltstyp zu ordnen.

## Tags

Mit Tags kategorisieren Sie Assets für schnelles Filtern:

- Tags in der Detailansicht eines Assets hinzufügen
- Die Bibliothek nach einem Tag filtern (immer nur ein Tag gleichzeitig)
- Einheitliche Namenskonventionen verwenden (z. B. `product-shots`, `2026-spring`, `logos`)

## Metadaten bearbeiten

Klicken Sie ein beliebiges Asset an, um dessen Detailansicht zu öffnen. Dort können Sie bearbeiten:

- **Alt-Text** — beschreibender Text für Barrierefreiheit und für E-Mail-Programme, die Bilder blockieren
- **Tags** — kategorisieren das Asset, damit es leichter auffindbar ist

::callout{type="tip"}
Setzen Sie immer einen Alt-Text für Bilder. Das verbessert die Zugänglichkeit für Nutzerinnen und Nutzer von Screenreadern und liefert Kontext, wenn Bilder vom E-Mail-Programm blockiert werden.
::

## Medien im E-Mail-Editor verwenden

Wenn Sie im [E-Mail-Editor](/guide/email-editor) einen Bildblock einfügen, können Sie aus der Medienbibliothek auswählen, statt eine neue Datei hochzuladen. So bleiben Ihre Bilder einheitlich und Duplikate werden vermieden.

1. Fügen Sie im Editor einen `/image`-Block hinzu.
2. Klicken Sie in den Bildeinstellungen auf die Bild-/Durchsuchen-Schaltfläche neben dem Feld **Bild-URL**.
3. Durchsuchen oder durchstöbern Sie die Medienbibliothek.
4. Wählen Sie das Bild aus — es wird automatisch in Ihre E-Mail eingefügt.

## Anhänge für transaktionale E-Mails

Dateien aus der Medienbibliothek lassen sich an [Transaktionale E-Mails](/guide/transactional) anhängen. Im Editor für transaktionale E-Mails enthält das Anhangs-Panel eine Schaltfläche **Medienbibliothek**, über die Sie eine gespeicherte Datei auswählen können, statt sie erneut hochzuladen.

Beim Versand über die [Transaktionale API](/api/transactional) werden Anhänge inline im Feld `attachments` als Base64-Inhalt oder als HTTPS-URL übergeben — sie werden nicht über eine Medienbibliotheks-ID referenziert.

## Sammelaktionen

Wählen Sie mehrere Assets aus, um eine Sammelaktion auszuführen:

- **Löschen** — die ausgewählten Assets entfernen

## Nutzung und Speicherplatz im Blick

Die Kopfzeile der Medienbibliothek zeigt eine Zusammenfassung wie „42 Dateien · 12 MB belegt“ — die Anzahl der Dateien in Ihrer Bibliothek und den gesamten Speicherplatz, den sie belegen.

So behalten Sie den Speicherverbrauch im Auge, während Ihre Bibliothek wächst.

::callout{type="info" title="Nutzung je Asset"}
Öffnen Sie ein beliebiges Asset: Sein Detailbereich zeigt eine einzelne kombinierte Anzahl der E-Mails (Vorlagen, transaktionale E-Mails und gespeicherte Blöcke), die es derzeit referenzieren — so erkennen Sie auf einen Blick, ob ein Bild gefahrlos gelöscht werden kann.
::

Themen sind explizite Zielgruppen — du bestimmst genau, wer zu welchem Thema gehört. Sie eignen sich ideal für die Verwaltung von Opt-in-Abonnenten, importierten Kohorten und geordneten Kontaktgruppen, die du mit Kampagnen ansprichst.

## Wann Themen, wann Segmente

| | Themen | Segmente |
| --- | --- | --- |
| **Zugehörigkeit** | Manuell — Kontakte werden ausdrücklich hinzugefügt oder entfernt | Automatisch — anhand von Regeln, die sich in Echtzeit aktualisieren |
| **Am besten für** | Importierte Kohorten, ausdrückliche Opt-in-Gruppen, Partner-/Kundengruppen | Dynamische Regeln auf Basis von Verhalten, Eigenschaften oder Interaktion |
| **Pflege** | Du verwaltest die Zugehörigkeit direkt | Pflegt sich selbst, sobald sich Daten ändern |

Nutze Themen, wenn du eine fest definierte Gruppe von Kontakten hast. Nutze [Segmente](/guide/segments), wenn deine Zielansprache von sich ändernden Daten abhängt.

## Ein Thema anlegen

1. Öffne **Zielgruppe > Themen**.
2. Klicke auf **Neues Thema**.
3. Gib einen Namen und eine Beschreibung für dein Thema ein.
4. Entscheide, ob du **Double Opt-in** aktivieren möchtest (siehe unten).
5. Speichere das Thema.

::callout{type="tip"}
Verwende klare, beschreibende Namen wie „Monatlicher Newsletter“ oder „Produkt-Updates“ statt generischer Namen wie „Thema 1“. Du wirst diese Themen in Kampagnen, Formularen und Automationen wieder referenzieren.
::

## Double Opt-in

Double Opt-in (DOI) ergänzt einen Bestätigungsschritt, wenn jemand einem Thema beitritt. Für öffentliche Anmeldeformulare ist das bewährte Praxis, weil es nachweist, dass die Person die E-Mail-Adresse tatsächlich besitzt.

### So funktioniert Double Opt-in

1. Ein Kontakt tritt einem Thema bei, das Double Opt-in erfordert (über Formular, Import oder manuell).
2. Sein Bestätigungsstatus wird auf **Ausstehend** gesetzt.
3. Eine Bestätigungs-E-Mail wird automatisch versendet (bei Formularanmeldungen; einige Admin-/Importwege fügen einen Kontakt als **Ausstehend** hinzu, ohne eine Bestätigungs-E-Mail zu versenden).
4. Der Kontakt klickt auf den Bestätigungslink.
5. Sein Status wechselt auf **Bestätigt** — er ist nun für Kampagnen berechtigt.

::callout{type="info"}
Kontakte mit dem Status **Ausstehend** werden von Kampagnen an ein Double-Opt-in-Thema ausgeschlossen. Nur **bestätigte** Kontakte (und solche mit dem Status **Nicht erforderlich**) sind eingeschlossen.
::

Double Opt-in ist eine Einstellung pro Thema (du aktivierst sie beim Anlegen oder Bearbeiten des Themas), der Bestätigungsstatus eines Kontakts wird jedoch einmalig auf Kontaktebene geführt. Eine einmalige Bestätigung deckt jedes Double-Opt-in-Thema ab, dem dieser Kontakt beigetreten ist — eine erneute Bestätigung pro Thema ist nicht nötig.

### Wann Double Opt-in sinnvoll ist

- **Öffentliche Anmeldeformulare** — dringend empfohlen, um Fake-Anmeldungen zu verhindern und den Besitz der E-Mail-Adresse zu bestätigen
- **Partnerimporte** — hilft, das Interesse zu bestätigen, bevor du mit dem Versand beginnst
- **Compliance-sensible Kontexte** — manche Rechtsräume verlangen eine bestätigte Einwilligung

Für interne Themen oder Themen, die aus deiner eigenen Anwendung heraus befüllt werden, genügt in der Regel Single Opt-in (ohne Bestätigungsschritt).

## Mitglieder hinzufügen

Du kannst Kontakte auf mehreren Wegen zu einem Thema hinzufügen:

- **Über das Dashboard** — nutze die Kontaktverwaltung, um einzelne Kontakte hinzuzufügen oder aus deiner bestehenden Zielgruppe massenhaft zu übernehmen
- **Beim CSV-Import** — weise importierte Kontakte im Rahmen des Imports einem Thema zu
- **Über Formulare** — verknüpfe ein [Formular](/guide/forms) mit deinem Thema, sodass neue Einsendungen automatisch hinzugefügt werden
- **Über die API** — Kontakte programmatisch zu Themen hinzufügen (siehe [API-Dokumentation](/api/topics))

## Mitglieder entfernen

Entferne Kontakte über das Dashboard aus einem Thema. Einen Kontakt aus einem Thema zu entfernen löscht ihn nicht aus deiner Zielgruppe — es hebt lediglich seine Zugehörigkeit zu diesem bestimmten Thema auf.

## Themen in Kampagnen nutzen

Eine Kampagne spricht genau **eine** Zielgruppe an: entweder ein einzelnes Thema **oder** ein einzelnes [Segment](/guide/segments). Du wählst im Zielgruppenschritt der Kampagne das eine oder das andere — es gibt keine Mehrfachauswahl von Themen, keine Kombination aus Thema und Segment und keine Ausschlussliste.

1. Wähle im Zielgruppenschritt der Kampagne **Bestimmtes Thema** und dann das Thema aus dem Dropdown.
2. Der Schritt zeigt eine **geschätzte Empfängerzahl** — die Anzahl der Kontakte, die die E-Mail tatsächlich erhalten.
3. Falls einige Themenmitglieder ausgeschlossen werden, nennt dir eine Warnung, wie viele und warum: Ein Kontakt wird übersprungen, wenn er keine E-Mail-Adresse hat, sich abgemeldet hat bzw. unterdrückt wurde oder (bei einem Double-Opt-in-Thema) die Bestätigung nicht abgeschlossen hat.

::callout{type="info"}
Die Schätzung nennt die *berechtigte* Zielgruppe, nicht die reine Mitgliederzahl. Ein Thema mit 1.000 Mitgliedern kann 920 berechtigte Empfänger anzeigen, wenn 80 Kontakte unbestätigt oder unterdrückt sind oder keine E-Mail-Adresse hinterlegt haben.
::

Wenn du stattdessen regelbasierte Zielansprache benötigst — zum Beispiel „Abonnenten, die in den letzten 30 Tagen eine Kampagne geöffnet haben“ —, baue ein [Segment](/guide/segments) und sprich dieses statt eines Themas an. Beachte: Segment-Zielgruppen unterliegen nie einer Double-Opt-in-Sperre und enthalten keinen themenspezifischen Abmeldelink.

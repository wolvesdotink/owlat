# Beispiele

Praxisnahe, sofort einsetzbare Code-Snippets für die häufigsten Owlat-Integrationen. Die Beispiele verwenden das TypeScript-SDK, mit curl-Varianten dort, wo ein direkter HTTP-Aufruf infrage kommt.

## E-Mails versenden

- [Willkommens-E-Mail](/examples/welcome-email) — eine personalisierte Willkommens-E-Mail versenden, wenn sich ein Benutzer registriert
- [Rechnungs-E-Mail](/examples/billing-email) — eine Quittung mit angehängter Rechnungs-PDF versenden

## Events & Automatisierung

- [Event-Automatisierung](/examples/event-automation) — Automatisierungen mit eigenen Events auslösen
- [Kontaktsynchronisierung](/examples/contact-sync) — Kontakte aus Ihrer Datenbank nach Owlat synchronisieren

## Infrastruktur

- [Webhook-Handler](/examples/webhook-handler) — Zustell-Webhooks mit Signaturprüfung verarbeiten
- [Mehrsprachige E-Mails](/examples/multilingual-email) — E-Mails in der bevorzugten Sprache der Empfänger versenden

# Pure decision cores, checked by scripts/check-purity.sh (part of `bun run lint`).

#   <path>              guarded file, or directory guarded recursively
#   !<path> [name...]   shell inside a guarded directory, with the pure names a
#                       guarded module may import from it

# A new module in a guarded directory is guarded by default. A shell line needs
# the reason it cannot be pure; prefer injecting the clock, random source or
# port over adding one.

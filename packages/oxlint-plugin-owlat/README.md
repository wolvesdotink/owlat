# oxlint-plugin-owlat

Owlat's own oxlint rules. The root `oxlintrc.json` loads `src/index.ts` through
`jsPlugins`, so every `oxlint --config …/oxlintrc.json` run (the root gates and
each workspace's `lint`) applies them. oxlint imports the source directly with
Node's type stripping: there is no build step, and the code must stay erasable
TypeScript with explicit `.ts` import specifiers.

| Rule                                       | What it enforces                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `owlat/require-suppression-reason`         | Every `oxlint-disable` / `eslint-disable` / `@ts-*` directive says why: a `-- reason` tail or a comment on the line above. TypeScript directives are recognized in every comment form the compiler obeys (`///` and block comments included, checked against the real compiler). Generated files are exempt. The root config keeps `@ts-ignore` / `@ts-nocheck` banned through `ban-ts-comment` and leaves the `@ts-expect-error` reason to this rule.                                                                                           |
| `owlat/no-test-environment-pragma`         | No per-file `@vitest-environment` pragma; the package's vitest config selects the environment. Matched with vitest's own pattern over the whole file text (comments, prose and strings alike). Deliberate exceptions are listed under the rule's `allow` option in `oxlintrc.json`.                                                                                                                                                                                                                                                              |
| `owlat/no-raw-keydown-listener`            | No raw `keydown` listener (`addEventListener('keydown', …)`, `onkeydown =`, VueUse `useEventListener(…, 'keydown')` / `onKeyStroke`) in `apps/web/app`: shortcuts are catalog ids bound with `useKeyboardShortcuts`, so they can be remapped and are listed on the shortcuts page. A listener that is not a shortcut (the dispatcher, an Escape or menu focus handler, passive instrumentation, a handler that resolves its keys through the registry) carries a suppression that says which. Test files are skipped.                            |
| `owlat/no-inline-backoff`                  | Exponential backoff is computed by `nextDelay` from `@owlat/shared/retryPolicy`, never inline. Outside test files and the policy module, reports a growing exponentiation (`a ** n` / `Math.pow(a, n)` with a literal base above 1 other than 10, or a base named as a factor, multiplier or backoff, and an exponent that is neither constant nor negated) and a wait multiplied in place (`x = Math.min(x * k, cap)`, `x *= k`, where `x` names a delay, backoff, retry, wait or interval, or ends in `Ms`).                                   |
| `owlat/no-test-in-loop`                    | No vitest `it` / `test` / `describe` declared inside a loop, including modifier chains, curried factories and tagged-template `.each` tables; use `.each`.                                                                                                                                                                                                                                                                                                                                                                                       |
| `owlat/no-document-body-reset`             | No test clears or replaces the whole `document.body` / `document.documentElement` (content assignment, `replaceChildren` and kin, draining loops). The vitest setups of `apps/web`, `packages/ui` and `packages/email-builder` unmount every mount after each test, so a test removes only the nodes it appended itself. Applies to every test file (`*.test.*`, `*.spec.*`, `__tests__/`); an optional `files` option narrows it further.                                                                                                       |
| `owlat/no-test-timeout-or-unreasoned-skip` | A per-test, per-suite or per-hook timeout names a constant from the root `vitest.timeouts.ts`, never a local number. No `retry`, in a test's options, `vi.setConfig` or a vitest config file. `.skip` / `.todo` (and `skipIf(true)`-style literals) need `// quarantine: #<issue> <why>` directly above; `skipIf` / `runIf` on a real condition stay allowed. An error; no baseline debt remains.                                                                                                                                                |
| `owlat/no-real-time-wait-in-tests`         | No real-clock sleep in a test file (`*.test.*`, `*.spec.*`, `__tests__/`): a `new Promise` resolved by a timer with a delay (global or `node:timers`), a `node:timers/promises` timer, a `sleep` / `delay` helper, `Bun.sleep`, Playwright's `waitForTimeout`. Await the event or drained queue, or drive fake timers: a sleep on a global timer (directly, or in a local or a relative-import helper) that the same function advances with `vi.advanceTimers*` / `vi.run*Timers`, faked, and without `shouldAdvanceTime`, is allowed. An error. |
| `owlat/no-wall-clock-in-tests`             | No elapsed wall-clock measurement in a test file: every `performance.now()` / `process.hrtime()` (globals or `node:perf_hooks` / `node:process` imports), and a subtraction or comparison between two `Date.now()` readings (stopwatches, deadline loops, clock spins). Single fixture timestamps such as `createdAt: Date.now()` stay allowed, and so do readings taken after the same function calls `vi.setSystemTime` on a faked `Date`. Warning, debt in the owlat lint baseline.                                                           |
| `owlat/no-polling-loop-in-tests`           | No polling loop in a test file: a `for` / `while` / `do…while` whose body awaits a sleep or tick (timer promise, `Promise.resolve()`, `flushPromises`, `nextTick`, or a local helper wrapping one) while a predicate decides when it stops. A fixed number of flushes (a counter moved only by a fixed, nonzero step) is fine. An error; no baseline debt remains.                                                                                                                                                                               |
| `owlat/no-crypto-primitives`               | HMAC signing (Web Crypto `importKey` / `sign` / `verify` / `generateKey` / `deriveKey` with HMAC, or an `importKey` whose algorithm is not a literal), any `timingSafeEqual` use and XOR-accumulate compares stay in the modules listed under `allow`.                                                                                                                                                                                                                                                                                           |
| `owlat/no-process-env`                     | Environment reads go through the env module: every access form of the `process.env` object (dotted, bracket, optional, destructured, `node:process` imports) is reported elsewhere in `files`.                                                                                                                                                                                                                                                                                                                                                   |
| `owlat/no-log-pii`                         | A process-log call (`logInfo` … `console.*`, under any import or local alias) carries no correspondent address or subject key unless every value it can take goes through a redaction helper (resolved by binding; each conditional branch counts); `// log-pii-safe: <reason>` opts out.                                                                                                                                                                                                                                                        |
| `owlat/convex-error-taxonomy`              | `ConvexError` is constructed or subclassed only in the modules under `allow`, and no bare `Error` is thrown inside a function registered with a public builder.                                                                                                                                                                                                                                                                                                                                                                                  |
| `owlat/no-raw-convex-builder`              | No use of the raw Convex `query` / `mutation` / `action` builders (resolved by import: aliases, namespace members and destructuring included) outside the wrapper module; a server-module namespace handed on untraceably, or loaded dynamically, is reported too.                                                                                                                                                                                                                                                                               |
| `owlat/use-threaded-session`               | A handler on an org-scoped builder takes the session the builder threads instead of calling a session-resolving helper; `// session: <reason>` opts out. An error; no baseline debt remains.                                                                                                                                                                                                                                                                                                                                                     |
| `owlat/feature-floor-in-builder`           | A gated family's handlers use its `featureGated` builder instead of asserting the flag inline or using a bare org-member builder; justified sites are listed under `allow`.                                                                                                                                                                                                                                                                                                                                                                      |

## Boundary rules

The last seven rules above replaced bash/awk gates (`scripts/check-*.sh`,
`apps/api/scripts/check-*.sh`) that matched text. They read the same scope
through options instead of the working directory: `files` and `ignore` are
repository-relative globs matched as a path suffix, test files are always
skipped, and each `allow` entry names the files (or, for the feature floors,
the `<path>:<function>` sites) it exempts together with its reason.
`scripts/__tests__/owlat-boundary-allowances.test.ts` fails an entry whose file
is gone or no longer needs it. Until the old scripts are retired, both run and
`bun run lint:ast-gate-parity` (`scripts/ast-gate-parity.ts`) diffs their
findings per rule.

The Convex rules need to know which names are public builders and the floor
each enforces. `src/lib/convexBuilders.ts` derives that table from the inputs
`apps/api/scripts/lib/convex-builders.sh` reads (its `CONVEX_BASE_BUILDERS`
classification and the `featureGated` compositions under `convex/`), once per
lint process, and resolves a call's builder by binding rather than by name.

## Adding a rule

1. Write `src/rules/<name>.ts` and its RuleTester suite in
   `src/rules/__tests__/` (oxlint's own `RuleTester` from `oxlint/plugins-dev`,
   wired to vitest in `src/__tests__/ruleTester.ts`).
2. Register it in `src/index.ts` and turn it on in `oxlintrc.json`.
3. If code still breaks it, configure it as `"warn"` and seed the ratchet
   baseline with `bash scripts/check-owlat-lint.sh --write-baseline`; the
   `lint:owlat` gate then fails on any new finding. Otherwise use `"error"`.

Keep the visitor cheap: the rules run on every linted file, so skip a file by
a plain text check in `create` when it cannot match, before asking for
comments or scope. Shared helpers live next to the rules: `src/ast.ts` (scope
resolution, imports, the test-file pattern), `src/waits.ts` (what counts as a
sleep or tick) and `src/fakeClock.ts` (whether vitest's fake timers drive a
piece of test code).
